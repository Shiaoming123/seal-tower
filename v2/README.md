# 斩妖塔 · 镇灯铺（v2）

第一人称走迷宫 + 卡牌战斗 + 背包构筑 + 跑货经营的网页 Roguelike。这是在旧原型（仓库根目录和 `first-cut/`）基础上的全量重做：旧代码和历史记录原样保留，新开发都在这个文件夹里。

## 一趟怎么玩

1. **镇灯铺接单。** 四张委托任选一张（灯匠要灯灰、绯绡要完整狐扣、药铺要鼠牙和蛾丝、镇长要负钟君的钟铜），再选一件兵器：照影剑（连招）、木挡板（入门，先挡后打）、引灯盘（烧货换伤害）。
2. **三层塔。** 每层是一座随机迷宫：照影廊 → 桥驿 → 钟楼。第一人称走格子，点小地图能自动走过去。路上有普通妖、精英妖、绯绡的狐市、事件、旧灯台（休息或磨剑）和宝箱，一次只处理一件事。每层最深处是守关妖，第三层是负钟君。
3. **卡牌战斗。** 每回合 3 点能量、抽 5 张。敌人头上明写下回合的打算：
   - **抢货**：灯鼠、夜市狐的攻击只要打穿格挡，就叼走你行囊里最值钱的货（不会抢装备）。
   - **蓄力**：蓄力那回合打出够多伤害就能打断，下回合的大招不会来。
   - **易碎部位**：狐妖的颈扣单次受伤太高会碎，想要完整的就用多段小伤害收尾。
4. **行囊就是构筑。** 兵器和工具是行囊里有形状的物件（剑 1×3、算盘 2×2、钩子 L 形……），放在行囊里它的牌就进牌组，卖掉或丢掉牌就没了。货物占格子、能卖钱、能交委托，有的牌还能把货烧掉换伤害。养元丹、扩囊衬布、金疮药是一次性消耗品。格子不够时，是多带一把兵器还是多装两件货，由你决定。
5. **回镇结算。** 交了的委托、打通的层数换成声望，声望解锁更难的签。

## 运行

需要 Node.js 22 以上。

```sh
cd v2
npm install
npm run dev          # http://localhost:5173，网址加 ?seed=任意文字 可复现同一座塔
npm test             # 规则单测 + 450 局机器人整局模拟
npm run build        # dist/，可直接部署到任何静态托管（魔搭 Static 空间等）
npm run build:offline  # dist-offline/index.html，单个离线 HTML 文件
```

端到端试玩（需要本机装有 Chrome，先 `npm run dev`）：

```sh
node tests/e2e.mjs http://localhost:5173
```

脚本会从标题一路接单、走迷宫、打牌、拿奖励、逛狐市，截图存到 `.cache/e2e/`，页面有报错就失败。`PORTRAIT=1` 用 390×844 竖屏跑。

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `src/data/` | 纯数据：卡牌 `cards.ts`、敌人与出招 `enemies.ts`、物品（货物 / 装备 / 消耗品）`goods.ts`、法宝 `relics.ts`、事件 `events.ts`、委托 `orders.ts` |
| `src/game/` | 纯规则，不碰 DOM：随机数 `rng.ts`、迷宫生成与寻路 `dungeon.ts`、战斗 `combat.ts`、异形背包 `bag.ts`、买卖与物品使用 `inventory.ts`、一趟的流程 `run.ts` |
| `src/render/` | 第一人称光线投射渲染 `raycaster.ts`（贴图墙、地面天花板投射、距离光照、精灵遮挡），三层的程序像素贴图 `textures.ts`，美术资源加载 `assets.ts` |
| `src/ui/` | Preact 界面，每个画面一个文件。舞台固定 1280×720（竖屏 720×1280）再整体缩放，换选项、看描述时页面不会跳动 |
| `src/audio/` | Web Audio 合成音效 |
| `tests/` | `rules.test.ts` 规则单测，`balance.test.ts` 整局模拟，`bot.ts` 模拟用的普通水平玩家，`e2e.mjs` 浏览器试玩 |
| `scripts/` | `prepare-assets.mjs` 从旧目录挑出用到的图并缩放压缩，`build-fonts.mjs` 按游戏用字裁剪字体 |

规则全部是可序列化的纯数据 + 纯函数：存档就是把 `RunState` 写进 localStorage，刷新页面能接着打；同一个签号永远生成同一座塔，方便复现问题。

## 数值怎么调

`npm test` 里的 balance 用一个不会读敌招、不会规划的普通机器人每种兵器打 150 整局。当前结果：照影剑约 21%、引灯盘约 20%、木挡板约 32% 登顶。会看意图、会护货、会打断蓄力的真人应该明显更高。改数值后看这三个数，太高说明太简单，太低说明太难；测试会在胜率超出 5%–85% 时失败。

## 新增文字之后

字体是按游戏实际用字裁剪的子集。加了新文案后跑一次：

```sh
npm run fonts
```

首次运行会把两份 OFL 原字体（马善政楷书、霞鹜文楷）下载到 `.cache/fonts/`。

## 素材

图像来自旧项目已生成的透明像素图（`../first-cut/sprites/`、`../assets/`），由 `npm run assets` 缩放压缩后放在 `src/assets/`。三层墙面、地面、天花板贴图由 `textures.ts` 程序生成。字体许可见 `../first-cut/type/`。素材授权范围见 `../docs/素材与许可.md`。
