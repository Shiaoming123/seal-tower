# 玩法优化方案（第二轮）

依据：仓库里的逐字聊天记录（40 条用户消息）、前一位 agent 的方向复盘（#114）和 v2 第一版的实测。

## 游戏想给玩家什么

用你的原话归纳：**模拟经营 + Roguelike + 战斗**，向《深空当铺》的资源判断和《杀戮尖塔》的预告、构筑看齐，要在很短时间里让人体会到巧思。前一轮复盘把最想要的瞬间说得很清楚：

> 玩家已经举剑，看见狐颈上晃着那枚扣，想起绯绡只收完整的，于是收剑，准备接它下一扑。换一趟，他只剩几滴血，就会当机立断把狐斩了，接受这笔生意少赚。

一句话：**你想带什么回去，决定了你这一剑怎么出、这一步往哪走。**

## v2 第一版离这个目标还差什么

| 目标 | v2 第一版 | 差距 |
| --- | --- | --- |
| 想带回的东西改变出手 | 只有狐扣（单次重击会碎） | 其余妖怪打法和取材无关，打法只看血量 |
| 深空当铺式的买卖判断（现在卖还是带着走） | 价格固定，每层一种货 ×2 | 没有「这里便宜、上面贵」的判断，也没有卖多了压价 |
| 走哪条路是个决定 | 走路没有成本 | 最优解永远是把整层清空，路线没有取舍 |
| 长线经营：声望、成就、熟客 | 声望只解锁难度 | 你提过的成就系统没有，第二趟没有新生意 |

## 这一轮做什么

### 1. 每只妖都有「取材条件」（核心）

战斗中敌人名字下方写明取材条件，实时显示「能取 / 已取到 / 取不了了」。达成就多拿一份好货：

| 妖 | 取材条件 | 多拿 |
| --- | --- | --- |
| 纸灯蛾 | 完整挡下它一次攻击后再击倒 | 灯芯 |
| 灯鼠 | 抢到货之后会钻洞逃跑：下回合之前击倒就追回 | 被抢的货 |
| 书虱 | 趁它没缩壳（不在「缩壳」回合）时击倒 | 完整墨壳 |
| 镜狐 / 夜市狐 | 单次伤害不到阈值，狐扣不碎 | 完整狐扣 |
| 灯蛾娘 | 打断一次「焚翅」 | 灯芯 |
| 守门黑狐 | 力量叠到 6 层之前击倒 | 狐毛结 |
| 负钟君 | 打断一次「蓄钟」 | 多一片钟铜 |

灯鼠改成**抢到就跑**：抢货之后它的下一招是「钻洞」，没在这回合打死，它就带着货逃走，这一战什么也拿不到。护货、速杀、放它走，三种选择都讲得通。

### 2. 行情：现在卖，还是带上楼卖

- 每层狐市有自己的**行情牌**：每种货的收价在 60%–160% 之间浮动，另有一种「高价收」×2。
- **同一种货卖多了会压价**：每卖一件，这家的收价降 1 石（最低 1 石）。
- 道友事件能**打听下一层的行情**，于是「这里便宜，带上去卖」成为一个能算的决定，但要占格子、可能被鼠抢。

### 3. 灯油：走路有成本

- 镇灯铺的斩妖人提着灯进塔。**每走一步耗 1 点灯油**，开局 90 点，最多 120 点。
- 灯油低时画面变暗；**灯灭后**看不清小地图（不再自动探路），而且妖趁黑每下多打 3 点。
- 补灯油：狐市买（20 点）；旧灯台可以选「添油」；**在行囊里把一份灯灰烧成 8 点灯油**——灯灰又多了一个用途：交单、烧来打架、还是烧来照路。
- 机器人清空一层平均要 64 / 74 / 84 步，所以想把每层都清空，必须花钱或烧灰买灯油；不想花，就得挑着走。

### 4. 长线：成就与熟客

- **成就**：首次登顶、完整狐扣、追回被抢的货、打断蓄力、灯不灭登顶等，每个成就给声望，在标题页可以查看。
- **熟客**：同一位委托人完成过一次，下次接他的单，酬劳更好，还会预付一件东西（例如灯匠先送 2 份灯灰）。
- **声望解锁**：声望累积后，镇灯铺货架上多出新装备（进入掉落和狐市），再往后解锁第四种起手兵器「算盘」（花钱流）。

## 不做的事

- 不增加同质的敌人数量：先让现有的 8 只妖都有自己的取材打法，再加新妖。
- 押运不回来。

## 怎么验收

- 机器人整局模拟：三种兵器登顶率保持在 15%–45%；灯油不应让机器人卡死在半路。
- 新增规则单测：取材条件、灯鼠逃跑、行情压价、灯油耗尽、成就记录。
- 浏览器端到端：从接单走到第二层，无报错。
- 真人试玩仍然是空缺：建议你或身边 3–5 个人试一趟，看是否有人「为了想带回去的东西改了一次出手」。
