## 工作流

1. 按下面的描述生成图片，存成 `v2/art/<文件名>.png`。文件名见每节表格，不带扩展名的部分必须完全一致。
2. 在 `v2/` 下运行 `npm run assets`。脚本会按用途自动缩放、压缩成 WebP，并覆盖占位图。只处理指定图片可用 `npm run assets -- lantern-spirit water-ghost event-peddler`。原图与导出的 WebP 哈希写入 `art/exports.json`，清单核对后标记为已替换。卡牌、法宝、立绘、营建、姿态这些新文件名，游戏已经在代码里预留，放进来就会自动使用，没有就继续用占位。
3. 运行 `npm run dev`，再运行 `node tests/gallery.mjs http://localhost:5173`。它会把每只妖的战斗画面和每个事件截图到 `.cache/gallery/`，用来检查新图在游戏里的效果（大小、位置、和场景是否搭）。
4. 运行 `node scripts/art-audit.mjs`，确认清单里这张图的状态变成了 `ok`。

**尺寸**（原图大于这个即可，脚本会缩小）：敌怪和人物至少 768 px 高；物品、法宝、营建图标 256×256；卡牌插图 512×256 横幅；事件物件至少 512 px；签文插画 960×540。

## 统一画风（每张图都适用）

照着现有的绯绡、纸灯蛾、镜狐、负钟君来画，保持同一套风格：

- **题材**：中式修仙、志怪。塔里的妖大多由灯、纸、碑、铜钟、市井旧物变来。
- **画法**：高细节像素画。硬边，颜色有限，可以有抖动，不要糊、不要写实照片感。
- **背景**：透明 PNG。只画角色或物件本身，不画地面和场景，脚下留一点阴影空间。
- **机位**：敌怪按第一人称迎面站位，正面或微侧 3/4 朝向镜头，看起来像要扑向玩家。主体居中，四周留 5% 左右的空白。
- **光**：左上方暖色灯光（灯笼黄），暗部偏冷青色。
- **色调参考**：照影廊用青绿石和朱红漆，桥驿用夜里的青灰石和湿木，钟楼用暗红砖和青铜。
- **人物**：比例正常，手指数量正确（每只手 4 根手指加 1 根拇指）。不要过于写实的真人脸，要像游戏原生角色。
- **尺寸**：敌怪与人物至少 768 px 高，物品图标 256×256，事件场景物件至少 512 px。

### 引魂灯 `lantern-spirit`
一盏飘在半空的旧纸灯笼，灯笼纸发黄、有破洞，破洞里透出幽绿的魂火。灯笼下垂着几缕像触须的红穗，末端烧焦。灯笼正面浮出一张模糊的人脸轮廓，嘴半张，像在吸东西。没有身体，悬空，下方是一团淡淡的绿火。尺寸偏小。

### 纸人童 `paper-doll`
纸扎铺里扎给死人的纸童子，约孩童身高。白纸糊的脸，两腮点着圆圆的胭脂红，眼睛是墨点画的，嘴角上翘得僵硬。穿红纸剪成的小褂，衣角、袖口有剪纸花纹，竹篾骨架从破口里露出来。双手各捏一张锋利的红纸刀片。整体轻飘飘的，脚尖离地。

### 火鼠 `fire-rat`（可选 `fire-rat-attack`）
和灯鼠一样大的鼠妖，但皮毛是焦红色，背脊一溜冒着火星的鬃毛，尾巴尖是一团小火苗。门牙发黑，嘴角沾着灯灰。眼睛橙黄发亮。四肢着地，弓背呲牙。可选扑击姿态：张嘴扑向镜头，前爪张开，火星四溅。

### 墨蛾 `ink-moth`
和纸灯蛾体型相当的蛾子，翅膀像浸透了墨的宣纸，深蓝黑色，翅脉是晕开的墨迹，边缘有洒金碎点。腹部是一只小砚台形状的硬壳，口器像毛笔尖，正往外滴墨。触角是两根细长的墨线。

### 水鬼 `water-ghost`
桥下淹死的人变的水鬼。上半身从水里探出（下半身是一团水和水草，看不到腿），皮肤青白、泡得发皱，长头发湿漉漉地贴在脸上遮住半张脸，只露出一只发光的眼睛和一张咧开的嘴。手臂细长、指甲发黑，缠着水草，向前伸出。身上不停滴水。

### 碑灵 `stele-spirit`
一块活过来的青黑石碑，约一人半高。碑身裂开几道缝，缝里透出金色的字光；碑面上的古字在流动。碑的两侧长出两条粗壮的石臂，碑顶像一张没有五官的脸，只有两道发光的刻痕当眼睛。底座是碎石，像脚一样扎在地上。

### 堕道者 `fallen`（另画 `fallen-strike`、`fallen-guard`）
走火入魔的斩妖人。装束和主角同一个门派（青绿外袍、红腰带），但衣服破旧发黑，红腰带变成暗紫色，袍角被妖气侵蚀得像烧过的纸。脸色灰白，眼睛发出暗红的光，额头有一道黑色的妖纹，嘴唇发紫。手里是一把剑身布满黑色裂纹的长剑，裂纹里有暗红光。三张同一角色、同一机位：
- `fallen`：持剑站立，剑尖斜指地面，阴沉地看着镜头。
- `fallen-strike`：向镜头劈砍，剑光拖出暗红残影。
- `fallen-guard`：横剑在胸前摆出架势，身体压低，剑身上浮出一层暗红的护体光。

### 棘碑 `thorn-stele`
一块被黑色荆棘层层缠绕的石碑，荆棘上长着暗红色、像倒钩的长刺，有些刺的尖端挂着血珠。碑面上原本的字被荆棘挤得碎裂。碑顶的荆棘纠结成一个像头颅的形状，中间一点暗红的光。没有手脚，但荆棘像触手一样向外伸。

### 铜傀 `bronze-puppet`
钟楼里守钟的青铜傀儡，约一人高。身体是用铜钟碎片拼成的人形：胸口是半口倒扣的小钟，四肢是铜管和链条，关节处有齿轮。背后插着一个大发条钥匙。脸是一张铸造的铜面具，只有两个空洞的眼孔，里面是暗金色的光。铜锈斑驳，青绿和铜黄相间。双拳巨大。

### 夜枭 `night-owl`
钟楼梁上的夜枭妖，体型比人还大。羽毛是夜色般的深褐和暗紫，翅膀张开，羽尖像刀片。脸盘是一张苍白的鸮面，眼睛巨大、金黄发亮，瞳孔细得像针。爪子是青铜色的，抓着一截断掉的钟绳。它讨厌光：迎着镜头的一侧眯着眼、羽毛炸起。

### 假狐商 `fake-fox`
冒充绯绡在塔里摆摊的白狐女。乍看和绯绡一样妩媚、穿华丽的狐市衣裳，但配色是冷白和灰蓝，九条蓬松的白尾巴在身后展开。笑容太标准，眼睛是冰蓝色的竖瞳。一只手拈着一枚铜钱伸向镜头，另一只手藏在宽大的袖子里，袖口露出一截锋利的指甲。腰间挂着一串账本和算筹。

### 纸扎娘娘 `paper-matron`
纸扎铺的老板娘，死后被自己扎的纸人抬进了塔。身形比纸人童高大得多，是一个用竹篾和彩纸扎成的贵妇人：高高的发髻上插满纸花，脸是白纸糊的，两腮点着胭脂，眉眼是墨画的，嘴角带着僵硬的笑。穿层层叠叠的大红纸裙，裙摆上剪着牡丹和铜钱纹。身后飘着几个小纸人童，手边浮着一圈锋利的剪纸刀片。守关妖，气势要足，但仍然轻飘飘的、脚不沾地。

### 堕道首座 `fallen-elder`（另画 `fallen-elder-strike`、`fallen-elder-guard`）
三十年前带队进塔的斩妖首座。比堕道者年长、威严：花白的长发披散，胡须凌乱，穿一件门派首座的玄色长袍（金线滚边已经发黑），袍子下摆被妖气侵蚀成破碎的灰烬。脸色青灰，双眼是燃烧的暗红色，额头的妖纹比堕道者更深更大。背后悬浮着七把残破的长剑，排成扇形剑阵。手持一把宽刃古剑。三张同一角色、同一机位：
- `fallen-elder`：持剑而立，背后剑阵静止。
- `fallen-elder-strike`：一剑劈向镜头，背后七把剑一起向前飞出。
- `fallen-elder-guard`：古剑竖在身前，七把剑环绕成一圈护盾，剑尖朝外。

### 传送阵 `portal`（可选）
地上一圈直径约两人宽的阵纹，青白色的光从阵纹里升起，形成一道半透明的光柱。阵纹由同心圆和八卦符号组成，外圈有十二个发光的符字。光柱里飘着细小的光点。画成从斜前方看过去的样子，光柱竖直向上。

### 妖窝拾荒 `event-den`
走廊墙脚塌出的一个大洞，洞口堆着碎砖。洞里是妖怪的窝：干草、碎布，上面堆着被叼来的杂物：灯笼骨架、铜钱、破伞、半截蜡烛、几个小包袱，最上面露出一个闪光的东西。洞深处一片漆黑，隐约有一对发光的眼睛（窝主可能随时回来）。

### 灯鼠货郎 `event-peddler`
一只人立起来的灯鼠，个头和灯鼠差不多，但穿着小小的短褂、戴着破斗笠，背上背着一个比它还大的包袱，包袱口露出各种小货物。两只前爪合在胸前作揖，满脸讨好的笑，胡须翘着。表情友善，不凶。

### 翻倒的货车 `event-cart`
一辆木制货车侧翻在地，一只轮子还在半空。车上的木箱、麻袋、坛子撒了一地，有的箱子摔开了口，露出布匹和瓷器。车辕断了一根。旁边没有人（车主在文字里出现）。

### 受伤的斩妖人 `event-hunter`
一位年轻的斩妖同行，穿和主角相近的门派服饰，但颜色是土黄和深蓝。他靠墙坐在地上，一条腿伸直、缠着渗血的布条，长剑横放在膝上，左手按着伤口，脸色苍白但眼神清醒，正抬头看向镜头。身边放着空了的药瓶。

### 灯神龛 `event-shrine`
嵌在墙里的小小神龛，木雕的龛顶有翘角和流苏，里面供着一尊巴掌大的灯神小像（手捧一盏灯的老者），供桌上一盏油灯亮着温暖的光，旁边有一个小香炉和几枚供奉的铜钱。龛框上贴着褪色的红纸对联。

### 照影池 `event-pool`
石板地上的一洼积水，边缘不规则，水面平得像一面镜子，倒映出暗色的梁柱和一点灯光。水面中央隐约映出一个持剑人影的倒影，比真实世界稍微模糊、发着淡淡的青光。

## 卡牌插图（P1，49 张，512×256 横幅）
