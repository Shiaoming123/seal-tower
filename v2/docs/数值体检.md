# 数值体检

2026-11-24 · GAME-004 建立，GAME-004B 调参后更新。这份文档写目标区间、从模拟看到的问题和调过的数；具体数字由 `tests/report.test.ts` 生成到 [docs/sim/report.md](sim/report.md)（会卖货）和 [report-nosell.md](sim/report-nosell.md)（不卖货），每次调参后重跑。

## 怎么跑

```bash
cd v2
REPORT=1 SEEDS=200 npx vitest run tests/report.test.ts          # 会卖货的机器人 → docs/sim/report.md
SELL=0 REPORT=1 SEEDS=200 npx vitest run tests/report.test.ts   # 不卖货 → docs/sim/report-nosell.md
```

机器人（`tests/bot.ts`）的规则：

- 打所有妖，守关妖最后打。
- 在狐市先交委托，再卖掉委托用不上的货（引灯盘留 3 份灯灰）。
- 气血低于一半时买药，灯油补到 70，钱多于 30 石就买牌，钱比法宝贵 25 石以上就买法宝。
- 不会整理行囊，不会挑路线，不会主动凑套装或淬炼。

所以报告反映的是「普通玩家随手打」的下限；真人会更强。

GAME-003A–C 日志里的胜率是用旧机器人测的，那几期之间的对比仍然成立，但绝对值偏低。

### 为什么改了两条目标

- **第一层普通妖。** 机器人只要看到妖要出手就先格挡，起手牌里平均有两张「格挡」（10 点），第一层妖一回合打 6–10，基本全被挡住。试过加血（×1.7）和加伤（+3），平均掉血都停在 2 上下，再加就会把第一层守关和精英一起推得太难。第一层普通妖的作用是教取材条件，威胁交给精英和守关。真人格挡不会这么准，掉血会多一些。
- **离开第三层剩的石。** 原定不超过 100，理由是「钱花不出去」。重看结算：活着回镇时身上的石折成库银，用来营建铺子。剩钱是跑商的利润，不是浪费，所以撤掉这一条，也不另加花钱去处（加了只会把钱换成战力，胜率回升）。现在离开第三层平均剩 123 石。

## 之前的报告看漏了什么

- **守关的血量、伤害倍率一直没生效。** `FLOOR_SPAWNS` 里守关的 `hp`、`dmg` 写了，但生成地图时只取了妖的种类。以前三层守关都写着 1 / 0，所以看不出来。已修。
- **同一只妖在不同层混在一起统计。** 守门黑狐在第三层既是普通妖（0.9 倍血）又是精英（1.5 倍血、+5 伤害），报告里合成一行，显示致死率 10%。按层、按类型拆开后，第三层精英守门黑狐的致死率是 40%，是当时最大的死因。现在报告每行都带层数和类型。
- **掉血按战后算。** 鼠牙坠战后回血，原先会抵掉一部分掉血。现在按战斗结束、结算奖励之前算。

## 看到的问题（GAME-004 时）

1. **第一层没有威胁。** 五种普通妖平均掉血 0–1.2，引魂灯 0。
2. **卖货的收益太高。** 卖货让胜率高出约 20–40 个百分点，离开第三层平均还剩 171 石。
3. **致死原因集中在三只大妖。** 守门黑狐、负钟君、夜市狐占了大部分死亡。
4. **卡牌选中率不可靠。** 机器人只会按伤害和格挡给牌打分，技法牌几乎都是 0 分。这一栏只用来发现「机器人完全不会用」的牌。

## 还没做的

1. **胜率还高 3–7 个百分点。** 下一步可以从起手气血或第三层精英的掉落下手，但要先看真人试玩：机器人格挡比人准，人可能本来就更难。
2. **卖货的提升还有 15–30 个百分点。** 不卖货的机器人会把用不上的货一直背着，这个对照本身偏弱。真人一定会卖货，所以以会卖货的胜率为准，这一条先不追。
3. **第三层精英致死 16–21%，比负钟君还高。** 机器人见妖就打；真人可以绕开精英。需要试玩确认玩家是否知道精英可以不打。
4. **兵器差距现在 4 个百分点**，引灯盘略高，不用动。
