# 数值体检

2026-11-24 · GAME-004。这份文档写目标区间和从模拟看到的问题；具体数字由 `tests/report.test.ts` 生成到 [docs/sim/report.md](sim/report.md)（会卖货）和 [report-nosell.md](sim/report-nosell.md)（不卖货），每次调参后重跑。

## 怎么跑

```bash
cd v2
REPORT=1 SEEDS=200 npx vitest run tests/report.test.ts          # 会卖货的机器人 → docs/sim/report.md
SELL=0 REPORT=1 SEEDS=200 npx vitest run tests/report.test.ts   # 不卖货 → docs/sim/report-nosell.md
```

机器人（`tests/bot.ts`）的规则：

- 打所有妖，守关妖最后打。
- 在狐市先交委托，再卖掉委托用不上的货（引灯盘留 3 份灯灰）。
- 气血低于一半时买药，灯油补到 70，钱多于 30 石就买牌，钱比法宝贵 25 石以上就买法宝。
- 不会整理行囊，不会挑路线，不会主动凑套装或淬炼。

所以报告反映的是「普通玩家随手打」的下限；真人会更强。

## 之前的模拟漏了什么

以前的平衡测试只看每把兵器的总胜率，而且机器人**从不卖货、不买法宝**。跑商是这个游戏的主线，等于没被模拟。补上之后：

| 机器人 | 照影剑 | 木挡板 | 引灯盘 | 算盘 |
| --- | --- | --- | --- | --- |
| 旧（不卖货、不买法宝） | 21% | 27% | 23% | 26% |
| 买法宝、不卖货 | 36% | 42% | 26% | 24% |
| 买法宝、卖货 | 63% | 50% | 63% | 61% |

GAME-003A–C 日志里的胜率是用旧机器人测的，那几期之间的对比仍然成立，但绝对值偏低。

## 目标区间

| 项目 | 目标 | 现在（会卖货） | 判断 |
| --- | --- | --- | --- |
| 随手打的胜率 | 30–40%，四把兵器相差不超过 10 个百分点 | 50–63% | 偏简单 |

| 第一层守关，平均掉血 | 8–14 | 2.4（灯蛾娘）/ 5.6（纸扎娘娘） | 太轻 |

| 精英，致死率 | 5–10% | 堕道者 5%、夜市狐 6%、守门黑狐 10% | 合适，守门黑狐压线 |

| 第三层灯油耗尽 | 10–20%（让灯油成为压力） | 13% | 合适 |

## 看到的问题

1. **第一层没有威胁。** 五种普通妖平均掉血 0–1.2，引魂灯 0。打第一层只是在点按钮，这也是用户说的「太板正」的一部分。
2. **卖货的收益太高。** 卖货让胜率高出约 20–40 个百分点。跑商应该有用，但现在它把战斗压力抵消了。离开第三层时平均还剩 171 石。
3. **致死原因集中在三只大妖。** 守门黑狐、负钟君、夜市狐占了大部分死亡。第二层的普通妖几乎不造成死亡。
4. **卡牌选中率不可靠。** 机器人只会按伤害和格挡给牌打分，技法牌几乎都是 0 分。这一栏只用来发现「机器人完全不会用」的牌，不能用来判断牌强不强。

## 下一步（GAME-004B）

按影响从大到小，每改一处就重跑报告：

1. 第一层普通妖伤害 +1～2（`FLOOR_SPAWNS[1].normal` 的 `dmg`）。目标：平均掉血 3–6。
2. 第一层守关伤害 +2～3。目标：平均掉血 8–14。
3. 卖货收益：每卖一件的降价从 1 石改成按售价的比例，或降低狐市收货的倍率。目标：卖货的胜率提升不超过 15 个百分点，离开第三层剩的石不超过 100。
4. 狐市加一样能持续花钱的东西，比如更贵的稀有法宝、删牌涨价，让钱有去处。
5. 调完后检查四把兵器的胜率差距。
