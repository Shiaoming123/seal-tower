# v2 重构说明：你的反馈怎么落到了新版里

这份文件按聊天记录里的反馈逐条对照新版的做法，方便以后接着改时知道每个设计是为了解决什么。

## 为什么重做，而不是在旧代码上改

旧仓库里同时堆着五条互不相通的原型（根目录斩妖塔、照影廊第一剑、一印两价、押运、第一人称猎妖供货）。最新的第一人称主线是在「卡牌规则 → 猎妖规则 → 押运规则」上一层层打补丁，地图只有一张 9×8 的固定格图，一趟只有三四个节点。代码是全局变量 + 字符串拼接的 IIFE，文案里大量特判。继续改只会更难懂。

新版保留了旧项目最值钱的部分：生成好的像素美术、世界观（镇灯铺、绯绡、灯灰、狐扣）、卖货与护货的核心想法，以及「一次只面对一件事」的原则。代码、规则、地图、界面全部重写。

## 反馈 → 做法

| 你的原话（摘要） | 新版做法 |
| --- | --- |
| 借鉴《深空当铺》的资源判断 + 《杀戮尖塔》的预告、流派、路线、构筑；三层，顶层小 Boss | 三层随机迷宫（照影廊 / 桥驿 / 钟楼），每层有普通妖、精英、狐市、事件、灯台、宝箱、守关妖；第三层负钟君半血变身。卡牌战斗，敌人意图常显 |
| 同一时间只面对一个事件 | 迷宫里每格最多一件事，走到才触发；战斗只有一只妖 |
| 流派：直伤、法宝、狗命（堆防御） | 三件起手兵器各带一套牌：照影剑（连招直伤）、木挡板（格挡反打）、引灯盘（烧货换伤害）。奖励牌按兵器偏向 |
| 资源要有取舍：货物、钱、血都能交换 | 货物能卖、能交委托、能被牌烧掉；血客用最大气血换钱；算盘把钱变力量；「撒钱」花钱打伤害；「以货挡灾」丢货换格挡 |
| 法宝像遗物；另有武器装备；背包像《背包英雄》那样每件东西占不同形状 | 法宝不占格子、纯被动。兵器与工具是行囊里的异形物件，**带在行囊里它的牌才进牌组**。行囊满了要在「多带兵器」和「多装货」之间选 |
| 一次性道具：加血上限、扩背包 | 养元丹（最大气血 +5）、扩囊衬布（行囊多一行，最多 6 行）、金疮药 |
| 敌怪掉落能稳定收集材料 | 每种妖有固定掉落；普通战斗 30% 掉一件基础装备，精英必掉中级装备 |
| 战斗戳两下就完了，没博弈、没数值变化 | 敌人有抢货、蓄力（打够伤害打断）、易碎部位（重击会碎扣）、叠力量、上虚弱/破绽。机器人模拟调过数值：普通水平机器人登顶率约 20%–32% |
| 文案故意文言，看不懂，指引太差 | 全部改成白话。敌人意图下面直接写「打你 7 点，只要打穿格挡就抢走完整狐扣」；首次遇到移动、战斗、抢货、蓄力、易碎部位都有一次性提示 |
| 押运按两下不知道怎么玩 | 删掉押运。第一人称迷宫：W/A/D 移动，或点小地图自动走；面板写明「前面 2 格：灯鼠」 |
| 点画面中间会误选选项；锁死的按钮没有下一步；卡关什么都点不了 | 没有隐形热区，所有操作都是明确的按钮。每个事件至少有一个永远可选的选项（单测保证）；奖励和事件的「继续」永远可点，装不下的货会说明留在原地 |
| 行囊描述长短不同导致页面上下跳 | 整个游戏是固定尺寸舞台再缩放；物品详情框固定高度 |
| 《吸血鬼爬行者》的第一人称 + 卡牌；2D 转 3D 要优化 | 自写光线投射渲染：贴图墙面、地面天花板透视、灯笼光照与雾、精灵遮挡、走路转身补间。战斗时妖站在走廊中间，手牌扇形排在下方 |
| 画面不要平面，UI 要拟物、要有书法字体 | 纸面卡牌、漆木面板、金边；标题用马善政毛笔字，正文用霞鹜文楷 |
| 敌人要有动作，不只是一张平面图 | 妖有呼吸、扑击前蓄势、受击闪白与抖动、死亡消散；灯鼠扑击换成挥爪的那张图；命中有刀光 |
| 世界观要讲清楚谁买货、妖在干什么、主角为什么回铺 | 镇灯铺接单界面直接写：妖偷光了镇上的灯油，你是给镇灯铺供货的斩妖人。每张委托写明委托人要货干什么 |
| 长线经营 | 声望（交委托、打通层数、登顶）跨局保存，解锁更难的签；四张委托对应不同打法 |

## 还没做 / 可以接着做的

- 真人试玩：你一直要求的 3–5 位初玩者样本，还没有。
- 手机实机：竖屏有布局，但只在浏览器模拟里跑过。
- 更多内容：每层敌人还偏少（共 8 种），可以继续加敌人、事件、委托；声望目前只解锁难度，可以加入解锁新兵器、新委托。
- 音乐：现在只有合成音效，没有背景音乐。
