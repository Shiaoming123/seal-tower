# 体验与文案独立评审（2026-11-24）

由一个独立的评审子 agent 完成：只读代码、在浏览器里按新玩家的路线走一遍（标题 → 镇灯铺 → 探索 → 战斗 → 奖励 → 狐市 → 事件 → 灯台 → 结局），不知道开发者之前的判断。它站在玩家的角度看三件事：界面会不会误导、文案说没说清、功能之间有没有接上。下面是 25 条发现和处理结果（REVIEW-001）。

同时处理了用户试玩时提的两点：

- **物品和物品组合的关系不清楚**，而这正是组成牌组的关键。
- **偏概念的词缺少引导**，比如「取材」。

这两点的改法写在文末。

## 物品组合和牌组的关系

用户反馈：物品和物品组合的关系有点模糊，这是组成牌组的关键。

- **牌组按来源分组**：打开牌组，先是「基础牌」（学牌、升级、移除都改这里），再按行囊里每件装备列出「来自铁剑 2 张」。身边配件给的加成写在组标题上，比如「身边配件让这组牌伤害 +2」；淬炼过的写「已淬炼，牌是升级版」。拿出一件装备，就少掉一组牌。
- **物品详情列出整张牌**：装备的详情不再只列牌名，每张牌带完整说明。
- **组合写清楚**：套装每个标签显示现在几件；配件写出现在挨着谁。
- **行囊说明讲关系**：「行囊就是你的牌组：装备放进来，它的牌就进牌组；配件挨着装备，牌变强；同标签的东西凑够数是套装。」

## 概念引导

用户反馈：偏概念的词缺少基础引导，比如「取材」。

- **名词表**：`src/data/glossary.ts` 收了 21 个新玩家猜不到的词，每个都有一句话的意思和一段怎么玩：取材、意图、格挡、消耗、心法、装备、货物、套装、配件、淬炼、易碎、侧袋、货堆、叠放、签文、委托、库银、灯油、行情、精英、守关。
- **点词就解释**：界面上带虚线下划线的词（战斗的取材、行囊的货堆、侧袋、套装、配件、易碎、结局的库银）点一下弹出解释，点别处关掉。
- **第一次遇到时提示一次**：第一次进战斗讲意图和格挡；有取材的妖讲取材；精英、守关、探索讲灯油和签文、委托；狐市讲行情和货堆；行囊按里面有什么讲装备、货物、配件、套装、易碎、叠放。每条都带「新概念」标记，点「知道了」以后不再出现。
- **帮助页**：新增「名词」和「按键」两节。

同一轮的全界面检查又报了几处，都修了：

- 手机上可点的名词只有 12–14 像素高：给它加了不影响排版的点击区。
- 竖屏顶栏的「灯油 90/120」超出 3 像素：竖屏只显示当前值，油量条照样能看出比例。
- 棘环说明在货架上被裁掉：缩短了。
- 桌面奖励画面顶栏的 Esc 被挤出：顶栏委托的货堆数改成小字「堆 N」，鼠标停上去有完整说明。
