# 长线经营与构筑 combo 方案（第三轮）

前两轮把「一趟」做扎实了：取材、行情、灯油、19 种妖、15 个事件。这一轮补两件更长远的事：**跨局的经营**，和**一局之内的构筑 combo**。

## 现在的问题

| 方面 | 现状 | 问题 |
| --- | --- | --- |
| 钱 | 一趟结束，身上的石和货全部清零 | 赚钱只在本局有意义。「回镇结算」几乎没有理由选：既不能存钱，也换不到东西 |
| 镇灯铺 | 只是出发前的选单 | 没有可以经营、可以变强的「铺子」，和《深空当铺》经营一家店的感受差得远 |
| 委托人 | 完成过一次就是老主顾，送一样固定的东西 | 关系不会加深，委托不会变大，报酬不会变好 |
| 委托 | 一趟只能接一张 | 没有「两张单抢同一种货」的取舍 |
| 行囊 | 只是装东西的格子 | 你发过的《背包英雄》参考里，物品会加成「相邻和对角」的物品，摆放本身就是构筑。我们的行囊只有占地的取舍，没有摆放的 combo |
| 牌池 | 约 38 张，四种兵器各玩各的 | 缺少「拿到它，整套打法就成型」的关键牌，也缺少把两种打法连起来的桥 |

## 一、长线经营：把镇灯铺做成你的铺子

### 1. 带货回镇：撤退变成一个真正的决定

- **活着回镇**（爬到塔顶，或者在楼梯口选「回镇结算」），身上的石，加上行囊里的货按镇上的价格折算，全部存进**镇灯铺的库银**。
- **倒在塔里**，身上的石和货全部丢失，只保留声望和成就。
- 于是第二层打完、背着一包值钱货站在楼梯口，就要选：上楼搏一把更大的，还是现在回去把钱落袋。这是《深空当铺》和撤离类游戏都在用的「见好就收」张力。

### 2. 营建：用库银升级铺子

库银用来营建镇灯铺。每项都让以后每一趟的开局变强，但不会强到不用动脑：

| 营建 | 效果 | 价格（库银） |
| --- | --- | --- |
| 账房 | 开局多带 15 / 30 石 | 50 / 120 |
| 灯油坊 | 开局灯油和上限 +15 / +30 | 40 / 100 |
| 药柜 | 开局带 1 瓶金疮药 / 再加 1 颗养元丹 | 50 / 120 |
| 货架 | 开局多带一件随机的一级 / 二级装备 | 70 / 160 |
| 学堂 | 进塔前先从 3 张牌里挑 1 张学 | 90 |
| 行囊匠 | 行囊开局是 5×5 | 140 |
| 订单柜 | 一趟可以同时接两张委托 | 110 |
| 狐市分号 | 塔里的狐市多卖一张牌、一件装备 | 100 |

### 3. 委托人的交情

- 每完成某位委托人的一张单，**交情 +1**（最高 5）。
- 交情越高，这位委托人的单**要的货越多，给的钱越多**：每级报酬 +25%，每两级多要一份货、声望多 1。
- 交情 ≥1 是老主顾，出发时先送东西（沿用上一轮的设计）。
- 配合「订单柜」同时接两张单：例如灯匠要 5 份灯灰、书院要 2 张碑拓。灯灰既能交单又能照路、还能烧了打架，两张单会抢你的行囊和灯油。

## 二、构筑 combo：让摆放和牌组都能连起来

### 1. 行囊相邻加成（配件）

新增 5 件小配件。它们自己没有牌，**加成摆在它周围 8 格里的物品**。行囊怎么摆，本身就是构筑：

| 配件 | 格子 | 效果（相邻和对角） |
| --- | --- | --- |
| 磨刀石 | 1×1 | 相邻装备的攻击牌伤害 +2 |
| 护身符 | 1×1 | 相邻装备的格挡牌格挡 +2 |
| 灯油壶 | 1×2 | 相邻的每份灯灰，在「灯火」这类按灯灰计算的牌里算两份 |
| 招财袋 | 1×1 | 相邻的每件货物卖价 +2 |
| 镇货符 | 1×1 | 相邻的货不会被抢 |

把磨刀石塞在两把剑中间，两把剑的攻击牌都 +2。招财袋放在货物堆中间，正好卖一个好价。镇货符护住最值钱的那一角。牌上显示的数字会直接带上加成，行囊里也会标出谁在加成谁。

### 2. 关键牌与桥牌（12 张新牌）

| 打法 | 新牌 | 用法 |
| --- | --- | --- |
| 照影剑 · 连招 | 疾风（0 费，本回合第 3 张攻击后再打 6）、收剑（按本回合攻击牌数得格挡）、**剑气纵横**（心法：每打一张攻击牌额外 2 伤害） | 0 费攻击牌越多，连招越长 |
| 木挡板 · 守反 | **铁布衫**（心法：每次获得格挡额外 +2）、固守（已有格挡时再加一倍） | 和「不动」「盾击」连成「越守越硬、硬了就砸」 |
| 引灯盘 · 灼烧（新状态） | 引火（施加灼烧）、**烧尽**（按灼烧层数打伤害）、清仓（烧掉所有灯灰，每份 4 伤害） | 灼烧每回合扣血、无视格挡；和怕火的纸人童、灯油壶连起来 |
| 算盘 · 本利 | 本利（拿钱，钱够多再抽牌） | 和撒钱、盘算、生息连成「先赚后花」 |
| 跨打法的桥 | **囤货**（心法：行囊里每 3 件货 +1 力量）、以货挡灾（已有） | 背着货就更强——但货也会被抢、占格子、卖不出去 |

### 3. 新法宝（4 件）

| 法宝 | 效果 | 连到哪里 |
| --- | --- | --- |
| 庖丁刀 | 取材成功时多拿 1 份同样的材料，再得 5 石 | 取材流：越会取材，越会赚钱 |
| 万宝囊 | 战斗开始时，行囊里每有 4 件货获得 1 力量（最多 3） | 囤货流 |
| 灯芯剪 | 灼烧每次多烧 2 点 | 灼烧流 |
| 剑谱残页 | 每回合第 4 张攻击牌打出时，能量 +2 | 连招流 |

## 怎么验收

- 机器人模拟：四种兵器登顶率仍在 15%–45%（机器人不营建、不摆配件）。
- 单测：撤退带回库银、死亡清零、营建效果、交情缩放、两张委托、相邻加成、灼烧、新牌与法宝。
- 浏览器端到端：接两张单进塔、营建页、带配件的行囊，无报错。
- 需要真人验证：撤退和上楼之间是否真的会犹豫；摆放配件是否让人愿意整理行囊。
