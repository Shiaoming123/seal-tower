# 从灯廊里看这笔生意

玩家站在斩妖人的位置上，接一笔货，亲自走到猎物面前。进塔前知道谁收什么，到岔路能打听货源，交锋时看得到下回合的危险，回铺还有一笔可核对的账。新线沿用旧试剑的单文件入口，接单页可切换侧面机位作对照。

## 玩家眼前发生什么

| 时机 | 看什么，做什么 |
|---|---|
| 铺里 | 决定给灯匠送两份灰、给绯绡取一枚完整扣，或只做散货。柜台选短刀、竹柄钩、木挡板，亦可起手配盘。 |
| 踏进灯廊 | 画面两侧是近处的墙柱，镜门在通道尽头。左转、前进、右转都按格结算。点小地图可看俯视图，金色箭头表示朝向。按方向键或 A/W/D 也能走。 |
| 到灯台和路口 | 每趟两处灯台各提供一次收灰或包扎。初层走灯架有灰，那边的镜狐扣缺角；走鼠洞见得到完扣，鼠却会偷灰。地上的灰不会无限刷。 |
| 妖在面前 | 先看敌招和预计受伤，再看下方四张牌。每回合有 3 点行动，0、1、2 费依次打出，末张多 2 点效果。鼠标悬停或触屏长按能放大读牌，长按松开会收起预览。点击一张就出一张，主动结束回合才轮到敌人。数字键 1–4 选当前顺序的手牌，E 结束回合。 |
| 把货用在刀口上 | 扬灰能加强下一击；带引灯盘时还可截招。完整狐扣可以在飞扑回合架住，或用引灯盘截招保住，迎上去打会把扣打断。竹柄钩能架翅挑芯，挡板能让下一击吃到反击加成；换工具会改下一战的牌组。 |
| 第二层鼠洞 | 桥驿会提前报货郎的换价。鼠洞水渠边只有一枚备用完扣，绯绡原单用 1 灰换，灯匠单或现货客用 3 灰换。首回合鼠会掀筐，攒够 5 格挡、用引灯盘截招或抢先击倒才能留住货。打赢后可以当场换，也可以带灰走。另一条灯架路照常收灰。 |
| 桥驿和回铺 | 能提前交货换周转，也能把货留到镜门以后。履约的熟客会在下一趟替你备灰或给灯盘折价。本趟现金和随身工具从头算。 |

## 同一张图怎样变成可走的场景

关卡规则保存格位、四向朝向和事件位置。俯视图直接画这组坐标。第一人称画面从当前格中心发出视线，求每个屏幕列首先撞到哪一面墙，再按距离投影墙高和纹理。地面、天花板和路牌也跟随同一个相机，前面的墙能遮住远处的牌子。移动一个格和转过直角时相机短暂插值；开启减少动态效果时直接停到目标位。鼠的身体和四肢有四组动作帧，狐和蛾另做面向玩家的透明图。材料状态、受击与卡牌效果由规则驱动。

规则里只有一个库存、一副当前手牌和一个当前事件。地图把走到格子的动作交给既有收货或战斗流程。打开路线图、看人物志、碰墙或点击场景背景都不结算战斗。浏览器重开页面能接回当前手牌。侧面机位与第一人称分别保存当局。

## 本次范围

三段分别经过灯廊、桥驿后廊、镜门，完整往返有四场交锋。签决定货源、东西猎路与部分敌招，关卡沿用一张小地图的结构。新线货袋容量为 5 份，用于验证消耗和交货之间的选择；原试剑线有完整的异形行囊。三种猎物中窃芯鼠为新增种类。真人首玩、长线经济和大牌池仍待观察。

## 本地复跑

在项目根目录运行 `node first-cut/check-crawl-world.cjs` 检查阻挡、转向、支线和镜门，运行 `node first-cut/check-crawl-cards.cjs` 重放 64 签的两张订单。`python first-cut/build_offline.py --verify-inventory <证据目录> --output <候选文件.html>` 会连同旧行囊、经济、押运和事件出口一起验证并生成离线包。

浏览器验证使用已安装的 Playwright 与 Chrome。`node first-cut/check-crawl-play.cjs --bundle <候选文件.html>` 走第一人称桌面 HTTP 与 390 宽离线触屏，保存两单的截图和输入记录。`node first-cut/check-hunt-play.cjs --bundle <候选文件.html>` 走侧面机位的两张订单。
