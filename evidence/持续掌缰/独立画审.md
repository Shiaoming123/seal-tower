# 持续掌缰独立画审

**签结：本次检查范围通过。** 绯绡五个姿态共十只手，每只画有四根长指和单独的拇指。最终包的停秤机位能同时看到两只手和连续的发梢、狐尾。留印动作经过袋口后束紧。走左辙、右辙或护箱时，390 宽画面至少有一块可见的对应路牌。

审查包为 `rein-bridge.html`，SHA-256 为 `c995d9548c13a70bf247274e14461e51617cb05c40021794c065bc58d6c2b7a4`。复核端为 1280 × 720 桌面 Chromium 鼠标，以及 390 × 844、DPR 2 的 Chromium 触屏模拟。桌面从环回 HTTP 进入并复算响应哈希，手机断网打开同一单文件。两端都从纸灯蛾、道友问价与首摊开始，用可见控件实玩。取证涵盖卖印、留印、血棘与墨巢双碑、常态查账、四段官道、三个驿市入口与交货账本。[逐路线记录](画审取证/采样记录.json) · [16 张贴图的原画及入包指纹](画审取证/贴图哈希.json)

## 绯绡的十只手

| 姿态 | 持柄或抚胸侧 | 另一只手 |
| --- | --- | --- |
| 停秤 | 四指搭胸，拇指向上且与食指间有清楚的指蹼 | 腕自右袖伸出，四长指顺搭左袖，拇指较高 |
| 报价 | 四指跨过铜柄，柄背单独露出拇指甲 | 四根长指横搭衣领，上翘的拇指从腕侧分叉 |
| 折臂 | 四枚指甲沿柄前缘排开，柄背有转向另一侧的拇指 | 四指可逐一循向掌面，拇指离开指群 |
| 收臂 | 四长指绕握，拇指从铜柄后面伸出 | 四指与离开的拇指仍分明 |
| 结账 | 四个指尖绕在柄前，拇指伏于上方 | 食指压钱面，拇指指腹托住铜钱下沿，另三指悬起 |

初稿的常态下手被衣袖完全遮住，报价胸前手也只显出四个明确指端。退修后逐张看了五张 1448 × 1086 透明源画，又从五张实际装载的 1200 × 900 WebP 分别取十个局部复核。移动实机的手指很小，精确指数量以源画、入包裁片和桌面画面交叉判断。[初稿](画审取证/初版双姿手部.jpg) · [入包五姿十手](画审取证/五姿十手.jpg) · [双端人物与柜台](画审取证/双端人物与柜台.jpg)

实机还退回过两种裁边。后退机位初版把下手露出来时，桌面右下发梢和袖边出现平切线，随后有一版又使右侧整片尾巴消失。终版复查报价、留印、举钱、末市初见及合账，发梢延至柜面后，白色尾梢与红褐尾身沿原轮廓伸展。成交过程中同时核了铜柄下眼圈与秤轴的连接。[两次裁边退修](画审取证/两次裁边退修.jpg) · [终版桌面停秤](画审取证/桌面-空手查账.jpg) · [终版手机停秤](画审取证/手机-空手查账.jpg)

## 器物与路面

| 对象 | 实际画面与处理 |
| --- | --- |
| 留印袋 | 初版终态仍有一块印和旧红布压在金绳下，袋口敞开。终版看到灯纹印由左上方飞向袋口，袋沿遮住印身，然后金绳系成蝴蝶结。两种姿态的狐狸刺绣、两侧流苏和桌面底部均连续。 |
| 岔口碑 | 近景血棘碑用暖石和红藤，远景墨巢碑用青灰缺石和蛾纹座。近大远小的关系可从两碑的宽高与门洞位置复查。桌面能直接读两行竖字，手机在画面下方另有全名、代价和收益按钮。 |
| 箭牌、结绳牌与承绳柱 | 修前单侧牌在右辙被车遮住。终版左右路肩给出同向箭头，左辙看右肩、右辙看左肩均可认方向。护箱的结绳牌靠前，真横索系在后面另两根木柱上，近景能分清标识与承重点。宽屏第一、三程的牌根及柱座也从河岸外与桥栏竖面移至路面内缘。 |
| 四类路障 | 首程为芦根浅洼，二程为碎岩，三程为断板石坑，四程为落瓦碎砖。宽屏初版的水洼压入河面、断板盖住桥栏，终版把两者落回铺石路内。390 宽复查了两辙，三类应对的下方文字及按钮可见。 |
| 三驿、交验 | 两端都经杉桥短市、碎潮水驿、挂铃栈，打开岔市后返回主线，第四程交三箱，最后回狐柜过关查账。路边驿名与下栏操作分开显示。 |
