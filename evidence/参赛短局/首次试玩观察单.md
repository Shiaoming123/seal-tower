# 首次试玩观察单

对象为 3–5 位此前没玩过这段试玩的人。每位单独使用同一个候选包，第一局只给一句话：“从照影廊起行，在末市结清这趟买卖。”由观察者征得参与者同意后在本机记录，不需要账号、姓名或联网。第二局可以自行决定要不要换个做法。

| 现场记录，一人一份 | 怎么记 |
| --- | --- |
| 匿名序号、试玩版本、设备 | 用 P1–P5，填写包哈希、设备、浏览器、键鼠或触屏。重复试玩沿用同一序号。 |
| 第一局用时 | 从首次看见可出剑界面到结账画面。另记中断或离开页面的时间。记实数，8–12 分钟是待检的目标范围。 |
| 看到行情后的行动 | 记录是否自己发现「商货」、如何选份数，是否先问价。场内不提示算盘公式。 |
| 第一次出手与结账 | 请玩家在成交前说出自己预计剩多少石、下一战会怎样；战后记录玩家有无自行指出收益或损失。 |
| 整理与资源压力 | 遇到囊满，看是否找到地上战利、缩减出售数量、保留一叠或放弃一件。记录点错处及需要指导的时刻。 |
| 押运分流 | 记录是否自发接单、催马或走三岔，每次买卖打算在哪里兑现，走错后有没有观察车尾和箱钱。把驿内阅读、手札暂停和离开页面分开记录。 |
| 第二局 | 记录是否愿意再玩、自己改变了哪个决定、理由是什么。若没再开局，记玩家原话。 |

两局之间只问“刚才哪一笔买卖最让你犹豫，为什么？”结束后再问“哪处操作或画面让你不知道接下来会发生什么？”观察结束后再解释玩法。

汇总给出实际样本数、时长区间和逐人的决定。优先修复反复导致误购、误弃或不知怎样推进的问题。浏览器自动跑批用来复现规则和按钮；两类记录分别归档。本轮样本数以实收记录为准。
