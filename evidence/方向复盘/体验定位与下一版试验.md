# 《照影廊》要让玩家为什么再进一次塔

2026-11-22 · 产品方向提案。本文诊断当前正式版，另外给出一个可撤回的试验。文中的「扬灰照影」「挑芯」及供货委托均为待测试规则。

## 先解决玩家为什么要挥这一剑

现在最完整的一条路是杀蛾、问价、逛店、走驿路、打狐、卖货。玩家很容易学会通关，却很难回答「这趟是我用什么办法做成的」。上轮把催马同签押运从 63.36 秒缩短到 34.69 秒，很好地修掉了等待；决定货物、战法和下次生意的规则几乎原样保留。[押运同签实测](../顺辙提速/独立实玩/独立玩法复审.md)

**我建议以回合制的「猎妖供货」做主玩法。** 玩家是给塔下镇灯铺供货的斩妖人。进塔前自己决定向谁承诺什么货。进塔后，妖身上有想带回的东西，包里的货又能救命。最想让玩家经历的一刻，是他看见夜市狐颈下那枚扣，本来已经举剑，却决定先守一招，因为他知道谁在等这枚完整的扣。第二趟，他应该想试一种能把这单做得更漂亮的战法。

想要的感受有先后。柜台上看见一笔想接的生意；交锋时发现原来的盘算出了岔子，手上还有改招的空间；回铺见到买主，明白为这笔生意冒的险究竟值多少。一路若只照提示选正确按钮，第二种感受就不会出现。

## 现版哪些地方已有价值

| 现版发现 | 对玩法意味着什么 |
| --- | --- |
| 算盘以入战时的现金计算首击。签 1 买零／一／两份绢的守关实测为 3／3／4 剑，净货利为 0／2／4 石。零份和一份又都剩 19 血。 | 第二份绢确实让玩家为利润付出一剑和气血；第一份在这个已报旺价的局面接近白赚。要看每一个边际选择。 |
| 饮棘钩配血珀佩可以把受伤变成剑伤和回血。同签「单钩直斩」4 手，「佩钩放血」2 手。 | 已有小型构筑。问题在于装齐以后常常只剩一次守关，来不及经历「先用半套、遇到克制、再补一件」的过程。 |
| 不买装备，合锋速杀后卖普通扣，10 石、19 血、3 手。为了完整扣守一次重击，12 石、15 血、4 手。 | 同一个敌人已经能让玩家在安全和货相之间主动取舍。值得以此为中心设计敌人。 |

| 走全三市后，带一灰、同样换算盘买两绢、同样出剑卖货。首柜卖印与留印都剩 19 血、3 手过关，末市分别余 30／33 石。 | 行商利润有时把提前变现的意义冲掉了。继续增加持币加伤的百分比，还可能让富裕路线同时更安全、更赚钱。 |
| 旧线的灯灰寄单确实能在下一局领货，熟客印记也会保存。但两条不同寄单可以在下个柜台就兑换成相同局面。 | 跨局已有持久数据；经营身份还需要用下一笔能谈成的生意来体现。 |

## 两个标杆给这个项目的启发

《深空当铺：可能是偷的》里，昂贵库存可能挡住玩家下一笔租金；选货时要考虑钱什么时候能收回来。官方更新还有个很好的细节：手电要真正带去垃圾场才影响拾荒风险。进店时的选择一直延续到店外。《照影廊》可以借走这种联系，让玩家拿在手里的订单改变出剑和备货。直接抄租金，反而可能惩罚正想试新招的参赛玩家。[开发者商店页](https://store.steampowered.com/app/4348910/) · [开发者 049 更新](https://store.steampowered.com/news/app/4348910/view/1843481262702145)

《杀戮尖塔》提前亮出敌人的意图，玩家仍要决定这回合值得挨几下、把什么留给后面。Mega Crit 的防守牌组示例还专门讨论少拿牌，因为额外一张牌会挤掉未来可能抽到的格挡。对应到本作，公开敌招和未来一站的供货，让玩家自己选择代价；妖物一次只登场一只也足以出题。借鉴细节与原始资料另列。[主创访谈](https://arstechnica.com/video/watch/war-stories-slay-the-spire-war-stories/) · [设计师的构筑示例](https://blog.playstation.com/?p=211260) · [标杆调研](标杆机制与来源.md)

## 第一张试验签怎样玩

1. **接单。** 镇灯匠要两份灯灰，愿出 6 石；绯绡要一枚完整狐扣。只给一个承诺位，可以任选一位，也可以自由散卖。每位买家在接单前展示交货时间和缺货处理。缺货可按明价补购，或改散售并放弃这单酬金。首个试验中接单即锁定本趟买家，驿柜可提前履约，也可放弃后改卖现货。放弃即失去约定酬金，本趟不能改签另一张高价单。首次失约仍能回铺，下局从基础条件重新接单。
2. **备货。** 起手剑能攻守。出发前只看到下一段妖情、下一处补给，知道墨蠹没灯芯、纸灯蛾有一枚灯芯，也能看到沿途哪家收货。只在两个补给时机调整装备；每次给少量有用的报价，可以拒买。异形行囊只在真有空间矛盾时请玩家整理。
3. **猎妖。** 沿用单敌固定机位。把妖材画在妖身上，角断、芯落、扣裂都能看见。主角亲手出剑。普通剑能速杀；上「挑芯钩」后，守住带芯妖的扑击，下一剑能把芯挑进囊里，折一份灰。一只妖只能掉自己身上的那枚芯。玩家已经会打时，一只蛾也有不同杀法。
4. **临场改招。** 所有人都能把一份灰扬向镜狐，照见它的真身，获得先手。持「引灯盘」时，这个先手还能截断已预告的扑击。两件东西凑在一起，玩家可以先从蛾身上取灰，再用这份灰抢断狐招；也可以留下灰交单，改用守势承伤取扣。守了一次、挑了什么、哪笔库存少了一份，都在原画面反馈。整套可由两种顺序取得，也允许中途换打法。
5. **回铺与再出发。** 买主当面验货，明确说出「你保住了扣」或「少的这份灰，被你用在狐关」。每趟至少有两次出货／补货的机会，第一次花光、受伤、囤货会限制第二次采购和猎妖。首轮先只测这一趟。

**战斗的区别由妖身上的东西和招式来承担。** 蛾教玩家把防守变成补货；披甲墨蠹让收灰套路失去来源，玩家可以消耗存货过关，或为了取壳改走这条路；镜狐把保血、保扣和保库存摆在同一招前。第一轮先做蛾与狐的可玩对照。墨蠹可以复用现有造型，留作专门检验两件套是否通吃的反例。出招前让人看懂敌情，命中后再表现断招和货相变化。

### 一笔可以当场算清的账

以下为**纸面试算**，数字用于暴露固定解。两局都已装备引灯盘，都是 7 血、3 石、2 灰，同一笔两灰 6 石的单，同一记狐扑。本回合守势或扬灰各占一次行动，下回合都用同一剑收尾。此表只测持盘时灰的机会成本。未持盘时扬灰能照出真身，仍须自行承受或应付该次扑击。承伤过招预计损 3 血；扬掉 1 灰截招可保住这 3 血。余灰散卖 1 石／份。

| 玩家已看见的供货消息 | 烧灰截招 | 护货承伤 |
| --- | --- | --- |
| 交货前能用 1 石补一灰 | 补回后履约，8 石、7 血 | 两灰履约，9 石、4 血 |
| 交货前最后一家已无灰 | 只能散卖剩的一灰，4 石、7 血 | 两灰履约，9 石、4 血 |

同样保住 3 血，前一种情形花 1 石，后一种少收 5 石。接下来若还要猎一次妖，血值得多少由玩家的装备和下一战决定。这里仅证明信息能改变代价。若玩家在两种情况下都毫不犹豫走同一路，这套设定仍得改。尤其要测「挑芯＋引灯」是否总能让玩家同时取得全部酬金、全血和满货。

## Roguelike 和长线经营各负责什么

- **一局之内有适应空间。** 第一次补给先让人靠半套装备做生意，第二次再给可能补全或改变打法的器物。签决定可遇的货源、妖情、报价组合；危险与已签合同的条款提前明示。给每局保留一条凭普通剑也能撤回的路线，缺某件装备仍有生意可做。保留固定签复盘，出现新局面才换签。
- **跨局有一个具体的人记得生意。** 若首轮好玩，再试镇灯匠成为熟客，允许下一次用唯一寄单位为他提前备灰；另一位熟客可留一件器物到第二柜，玩家隔一战再决定是否出钱买。二选一就会改变进货时机。初始血、现金和锦囊照旧重置，跨局关注获得了什么交易条件。失约可改接现货单慢慢重建关系。
- **经营要有周转。** 早卖拿到的钱必须来得及救下一次采购或打断一次危险；保留贵货必须真实占囊、占流动资金。有账面利润、却接不起下一单也属于合理结果。先试一个供货承诺与一个寄单位，暂缓复杂债务、声望等级和多币种。

## 怎么决定值不值得重构

**建议先调整核心循环，复用底层战斗结算、背包与交易。** 押运留给喜欢走驿路的玩家，在新试验中作为可选补货路线。美术优先画清敌人要扑、灯芯被挑出和狐扣破裂这几帧。地图扩三层、更多同质敌怪和随机词条在验证后排期。

| 验证 | 做法及判退条件 |
| --- | --- |
| 桌面推演 | 将血、现金、货和承诺分别记账。让优先履约、优先用货、逢战速杀与临场改策走相同签。对调货源、改变敌招，再拿掉一件组合装备。若一种简单策略在存活、履约和结余都不吃亏，或某件核心物品从不值得放弃，先重写规则。 |
| 可玩片段 | 用相同开局做一条熟悉线、两条调换货源或妖情的签。固定视角，每次只开一个事件。具体班次为首柜接单备货 → 第一只带芯蛾 → 第一只镜狐 → 驿柜补货或提前交单 → 第二组蛾、狐逐只出现 → 回铺结清。第二组改变其中一个已预告的条件，复用同两种敌人。记录两次镜狐前有几份灰、是否烧灰、哪次交易让人改招。若只搭到第一只镜狐，所得结论只覆盖一次决策。 |
| 首玩观察 | 请 3–5 位不了解设计的人先走新版一趟，不提示最优解，记录第一次主动放弃什么、有没有发现货可用于战斗、出门时是否看下家。结算时将「退出」「重开这张签」「换签」放在同样显眼的位置。先记自愿再开的原因和行为，之后才邀请对照体验旧线。小样只用于发现问题。 |
| 方向闸门 | 至少两种公开局面能让同一货物呈现相反且玩家说得通的用途；暂以 3 人能复述一次取舍、至少 2 人自愿再开且尝试不同打法作为进入扩内容阶段的门槛。这是原型的制作决策，不是重玩率估计。若只会算价，先改敌人；若只看血条，先改订单；若两者都懂仍想退出，重做猎妖这一刻的动作与奖励，再决定是否扩内容。 |

本轮完成了标杆核查、现版规则复跑和独立反例评审。新版的取材、订单与熟客经营仍是假设；两轮可玩片段和真实玩家观察是下一次投入制作的依据。
