# 桥驿入洞 · 独立画审

**签 1 的「桥驿 → 岔口 → 鼠洞」通过画审。** 最明显的进步在最后一步。旧镜头丢掉路牌后，玩家面前先剩一堵空墙，随后整只鼠与货筐同时跳入。终稿里，路牌从左肩滑过去，镜头落脚再转，鼠尾、躯干、前爪与右侧的筐依次进入视野。玩家能看懂自己从哪里来、敌人在什么位置。可直接播放两段同签对照，左为旧版，右为终稿。[1920 宽动态对照](画审对照/1920宽-同签动态对照.mp4) · [390 宽动态对照](画审对照/390触屏-同签动态对照.mp4)

| 检查 | 实机观察 |
| --- | --- |
| 离开桥驿 | 390 宽从货架滚到底部再点出发，旧版直接跳回页顶。终稿从当前货签开始变暗，本次采样 179–228 毫秒全窗被遮住，256 毫秒已在新场景页顶，随后灯台亮起。桌面也能看完整段过渡。[触屏全窗连续帧](画审对照/390触屏-全窗离店.jpg) · [桌面全窗连续帧](画审对照/1920宽-全窗离店.jpg) |
| 步行与左转 | 沿鼠洞走时，近柱转角及横向石缝很快从画边退出，远窗与门洞移动较慢。1920 宽旧图的侧柱曾拉成大片斜刷纹，终稿能追到砖缝绕柱的位置。左转时，近处岔口牌向右扫出，鼠洞牌从左进入，再停于新方向。紧贴镜头的石面仍会放大成粗像素，最近的一帧材质细节较弱。[1920 步行](画审对照/1920宽-沿鼠洞走.jpg) · [1920 左转](画审对照/1920宽-岔口左转.jpg) · [390 左转](画审对照/390触屏-岔口左转.jpg) |
| 鼠洞交接 | 初稿的目的牌正对玩家前进轴线，鼠全身半透明显现。终稿把牌立到左肩；390 宽第 151 毫秒从其右侧经过，约 380 毫秒见鼠尾，443 毫秒见侧身，505–547 毫秒前爪和筐都已入镜。停稳后接战没有再换位置或重放一次进场，也没有看到石面盖住已露出的鼠脸。[390 交接连续帧](画审对照/390触屏-鼠洞交接.jpg) · [1920 交接连续帧](画审对照/1920宽-鼠洞交接.jpg) |
| 货筐与水渠 | 初稿中筐旁水面太暗，酷似普通地板。终稿保留暗渠的环境光，石唇与青绿水面现可分辨。另走一局放弃守筐，249 毫秒的实绘帧显示铜扣落在两道石唇之间，后续掉落页显示「货筐落水，完扣换不到了」。[货筐与落水局部](画审对照/护筐水渠.jpg) |
