## 为什么

机制评审 A#16 指出：10 支签文里多数只是小加减，玩家看了签不会因此做出不同的选择。用户要求的方向是「以玩家感受为主」，每层开始抽的签应该是这一层的一个问题。

## 改了什么

每支签现在都在问一件事。改动只碰了四支，再加一支新的：

| 签 | 改前 | 改后 | 它在问什么 |
| --- | --- | --- | --- |
| 雨夜 | 灯油多烧；收货每件多 1 石 | 灯油照旧多烧；收货每件多 2 石，签文直接写「带上楼不如在这里卖」 | 货是现在卖，还是带上楼按库银倍率折算 |
| 香火旺 | 每个事件回 5 气血 | 每个事件回 8 气血；旧灯台能做两件不同的事（歇、磨剑、添油里挑两样） | 路线要不要绕去灯台和事件 |
| 精英巡夜 | 精英血 +15%，多给 20 石 | 血量和 20 石不变；前两层精英的法宝从一件变成三选一 | 打不打精英 |
| 货紧（新） | — | 在这一层的狐市交委托，报酬里的石翻倍，回镇再交就没有 | 委托是不是现在交、货要不要留着 |
| 太平 | 权重 2 | 权重 1 | 少抽到「什么都不问」的签 |

其他签（集市日、妖潮、月明、迷雾、灯会、血月）本来就带着取舍，没有动。

界面跟着改：

- 旧灯台在香火旺时写「香够用两回」，做过的选项变灰并写「已经做过了」，剩下一回可以以后回来用。
- 狐市交委托的按钮在货紧时写「（货紧，石翻倍）」。
- 名词表「签文」的解释改成「每支签都在问你一件事」，并举出这三个例子。

精英巡夜一开始把精英血量也提到了 +25%，模拟里木挡板的胜率掉了约 6 点（机器人每只精英都打），所以血量留在 +15%。

## 验证

| 检查 | 结果 |
| --- | --- |
| 单测 | 111 项通过。新增：香火旺灯台两次且不能重复、平时一次、货紧只在狐市翻倍、精英巡夜法宝三选一 |
| 模拟 400 局 × 4（对比同一版本的 main） | 照影剑 37 / 木挡板 24 / 引灯盘 40 / 算盘 43%，main 是 35 / 26 / 40 / 40，差别在随机波动以内 |
| 机器人 | 灯台逻辑改成能用两次（否则香火旺的灯台会把它卡住，平衡测试就是这样报出来的） |
| 模拟 200 局（入库报告） | 会卖货 37 / 22 / 41 / 41%，不卖货 19 / 15 / 26 / 20%。木挡板在 200 局里比 main 低约 5 点，400 局只低 2 点，按波动看待；它本来就是最弱的起手，留给后续单独调 |
| 行囊贴图、死按钮、全界面 | 0 处、0 个、三种尺寸都是 0 处 |
| e2e | 桌面、竖屏都通过。竖屏手牌叠得紧，第二张牌盖住第一张的中间，测试原来点牌的正中间会被挡住；改成点牌露出来的左边缘，和玩家实际点的位置一致 |
| 浏览器 | 香火旺灯台：歇一会后变灰「已经做过了」，说明写「还能再做 1 件」，再选一项后离开 |

## 限制

- 机器人不会因为签文改变路线，所以模拟只能看出「没把游戏变难或变简单」，看不出签文是否真的改变了玩家的选择。这一条并入 GAME-001 真人试玩。
- 货紧没有专门的音效和画面，用的是默认氛围。
