- 同步 UI-002 后独立画审复现两个阻断。正常迎战时假狐与玩家在同格，场景投影使立像冲出屏幕，390 宽时整只妖不可见。纸扎娘娘靠近时头部会被固定在屏幕顶端的提示挡住，且旧的窄屏图片宽度限制会从左侧挤掉构图。
