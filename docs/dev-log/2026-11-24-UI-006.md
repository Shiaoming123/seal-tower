## 为什么

用户 11-24 用 iPhone 在魔搭页面里打开游戏，镇灯铺（接委托、选兵器）有三处问题：

- 第五张委托（镇长）被「② 带一件兵器」的标题压住。
- 兵器卡之间露出后面的字（「路」「灭」「全」「周」）。
- 委托卡下半截大片空白。

## 原因

手机上游戏放在一块 600 宽的竖版舞台里按比例缩放。镇灯铺在竖屏下是单列网格，行高写的是 `auto`，三块区域又各自设了 `min-height: 0`。页面比屏幕高时，网格把三块压成一样高（各 284），内容溢出、叠到下一块上：

- 委托区溢出，第五张卡压在兵器标题上；
- 委托区底部的提示框跑到了兵器卡后面，就是卡片缝里透出来的字。

委托卡在竖屏下写死了 200 高，内容只有一百出头，所以空着半截。

## 做了什么

| 改动 | 说明 |
| --- | --- |
| 竖屏网格行改成 `max-content` | 每块按内容高度排，页面变长就滚动（`.town-screen` 原本就允许竖向滚动） |
| 竖屏委托卡高度 `auto`，最少 120 | 不再空半截；同一行两张卡仍等高 |
| 全界面检查加「文字重叠」 | `v2/tests/overflow-check.mjs` 原来只查文字超出自己的框、被裁掉和按钮点不到，查不出一块区域压到另一块上。现在也比较不同元素的文字有没有叠在一起 |

重叠检测怎么避免误报：

- 只比较同一图层的文字。图层以最近的绝对或固定定位祖先为界，所以弹窗盖住游戏画面不算。
- 文字先按所在的滚动框、裁剪框截掉看不见的部分再比较。
- 扇形手牌本来就互相叠着，上面的牌挡住下面的，排除。

另外加了 `ONLY=phone-short` 这样的开关，可以只跑指定尺寸。

改之前用新检测在手机矮屏（390×664）跑了一遍，它报出了镇灯铺的两处重叠：委托卡压住兵器卡、委托提示框在兵器卡后面。正是截图里的问题。另外只报了一条：战斗里扇形手牌互相叠着，属于设计如此，已排除。

## 验证

| 检查 | 结果 |
| --- | --- |
| `node tests/overflow-check.mjs`（含新的重叠检测） | 桌面 1280×720、竖屏 390×844、手机矮屏 390×664 都是 0 个问题，0 个页面报错 |
| `node tests/e2e.mjs`（1280×720） | 通过，无页面报错 |
| `PORTRAIT=1 node tests/e2e.mjs`（390×844） | 通过，无页面报错 |
| 浏览器 390×664 | 三块区域依次排开（委托区 355 高、兵器区 396 高），页面可以滚动，「进塔」按钮滚到底部可以点到。[修复前](assets/UI-006-town-before-390x664.jpg) · [修复后顶部](assets/UI-006-town-after-390x664.jpg) · [修复后底部](assets/UI-006-town-after-bottom-390x664.jpg) |

只改了竖屏的样式，桌面版的镇灯铺不受影响。

## 限制

- 魔搭手机页面的可视区域是按 iPhone 估的（390×664）。没有在别的手机型号上实测。
- 背景图只铺满第一屏，往下滚是深色底，没有改。
