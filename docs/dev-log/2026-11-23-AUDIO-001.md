## 为什么

用户反馈背景音乐和音效「做得不好」、整体「缺少商业游戏的沉浸式体验」。之前只有配乐和战斗音效，走在塔里时，配乐一停就什么也听不到；所有楼层共用同一个混响；妖站在拐角也听不到动静。这一轮补的是「这个地方本身的声音」。

## 做了什么

- **每层的环境声**（新 `v2/src/audio/ambience.ts`）：每处一层循环底噪（用两条不同速率的慢 LFO 调制，听起来不像循环），再随机散落单次声音，左右声道随机摆位。
  - 镇灯铺：街上的低声嘈杂、远处更夫敲两下梆子、檐下风铃、货郎的小铃。
  - 照影廊：长廊里的穿堂风、木头吱呀、纸灯笼被风吹动、远处风铃。
  - 桥驿：桥下流水（低频水声加密集的小水泡）、滴水、拴着的船吱呀作响。
  - 钟楼：风从百叶窗里吹过的呼啸（共振带通慢慢扫频）、头顶远处的大钟、铁链、夜枭。
- **签文改变环境声**：雨夜加雨声与密集雨滴；迷雾把整层环境声闷住（低通 800 Hz）；灯会远处放鞭炮、敲鼓；血月有低沉的嗡鸣和心跳；月明多几声夜枭。
- **战斗时压低环境声**到 35%，换楼层时淡入淡出。
- **每处不同的混响空间**（`engine.ts` 的 `setRoom`）：镇上开阔、短；照影廊是木廊；桥驿潮湿、发闷、短；钟楼很大、尾音长。切换时两个混响交叉淡化，没有爆音。配乐也走这个混响，所以每层的音乐听起来像在那个地方演奏。
- **按地面材质的脚步**（`sfx.step(surface, rain)`）：照影廊是木地板，偶尔吱一声；桥驿是湿石板，带水声；钟楼是石头，带砂砾的摩擦。雨夜任何楼层的脚步都带水声。左右脚轮流，略有音高差。
- **妖的叫声**（新 `v2/src/audio/voices.ts`）：每种妖一种声音。蛾子扑翅膀，鼠吱吱叫，书虱咔哒响，狐狸叫，守门黑狐低吼，负钟君铜钟嗡鸣，引魂灯噼啪作响，纸人沙沙响还带笑声，水鬼呜咽，碑灵石头摩擦，铜傀金属碰撞，夜枭叫，堕道者低声念咒。
  - 叫声来自妖所在的方向，左右声道按相对朝向摆位；越远越小、越闷，混响越多；在身后或还没看见时声音更闷。
  - 5 格内的妖每 2.6 秒有一定几率叫一声，同一只至少隔 7 秒；第一次看见某只妖时立刻叫一声。
  - 开战时妖先叫一声。
- **战斗配乐随局势加层**（`music.ts` 的 `setIntensity`）：
  - 0 级：原来的鼓点和琵琶。
  - 1 级（妖剩六成血以下、你剩 55% 以下，或打到第 6 回合）：加反拍鼓、更密的木鱼、低音筝。
  - 2 级（任一方剩三成血以下，或守关妖第二阶段）：再加双鼓、每两小节一声锣、低八度琵琶，速度快 8%。
  - 层次逐拍加入，不重启乐曲。
- **抽牌声**：开战和每回合开始时，每张牌一下纸声。

## 验证

| 检查 | 结果 |
| --- | --- |
| `npx tsc --noEmit` | 通过 |
| `npm test` | 54 项通过 |
| `node tests/e2e.mjs`（1280×720） | 通过，无页面报错 |
| `PORTRAIT=1 node tests/e2e.mjs`（390×844） | 通过，无页面报错 |
| `node tests/audio-check.mjs` | 无报错；静音底噪 0；最高峰值 0.47（锣、重击），无削波 |
| `node tests/audio-demo-check.mjs docs/audio-demo` | 15 段试听全部能解码、有声音、有左右差异 |

响度（Chrome 总输出，峰值 / RMS；数值越大越响）：

| 类别 | 结果 |
| --- | --- |
| 配乐（探索） | 0.11–0.20 / 0.013–0.027 |
| 环境声 | 0.03–0.06 / 0.005–0.009；雨夜 0.014（故意更明显） |
| 脚步 | 0.06–0.09 / 0.005–0.009 |
| 妖叫（1.5 格） | 0.04–0.15 / 0.003–0.015 |
| 战斗配乐 0 / 1 / 2 级 | RMS 0.025 / 0.034 / 0.041 |

环境声比配乐低约 10 dB，妖叫和脚步差不多响，打起来最紧张时配乐比开局响约 4 dB。

### 顺手修掉的测试问题

`tests/audio-check.mjs` 以前用 `import("/src/audio/sfx.ts")` 拿音频模块。改过文件后，Vite 给页面里的模块加了 `?t=…`，测试拿到的是另一份模块、另一套音频引擎，游戏自己的镇上配乐一直在底下响着，所有测量和录音都混进了这段配乐（这次实测底噪 0.013）。现在测试从页面已加载的资源里找到同一个模块地址再导入，开测前先停掉游戏自己的声音，并先测一次静音底噪（现在是 0）。之前提交的试听片段可能也混进了配乐，这次已全部重录。

我还发现守门黑狐的低吼里，颤音直接叠加在包络上（±0.5），声音在包络结束后还在响，已改成只在包络内调制。

## 限制

- 全部是合成声音，没有采样。妖叫声和流水比较像「示意」，不如录音逼真；如果以后要换成授权的音效素材，接口（`creatureCall`、`setAmbience`）不需要改。
- 妖叫声不考虑墙的遮挡，只按直线距离和朝向计算。
- 我没法自己听，响度只靠测量。音色需要真人戴耳机听过才算数。评审待安排。
- 未在实体手机上验证性能（每层同时有 2–3 条循环底噪和若干单次声音）。
