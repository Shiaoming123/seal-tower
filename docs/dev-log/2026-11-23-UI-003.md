# UI-003 沉浸感：场景氛围与动效

2026-11-23 · Claude（工程）· 分支 `claude/ui-003` · 起始提交 `313cffa`

## 为什么

用户反馈游戏「太板正，缺少商业游戏的沉浸式体验」。这一轮补的是画面上「活着」的那一层：空气里有东西在动，进楼层和遭遇有仪式感，打中有分量。

## 做了什么

- **环境粒子与天气**（新 `v2/src/render/fx.ts`，叠在 3D 画面上）：照影廊是暖色浮尘，桥驿是飘动的水汽光点，钟楼是上升的火星。签文会改变它：雨夜下斜雨并整体偏冷蓝，迷雾飘大团雾气，血月火星变红并压一层红色，月明偏冷光，灯会偏暖。约 30 帧刷新，不占多少性能。
- **楼层转场**：每到一层先黑屏淡入，大字写出楼层名（「第一层 · 照影廊」）；签文卡等标题淡出后再出现，不再叠在一起。
- **遭遇转场**：开战时画面一闪、镜头从略近处拉回，写出「遭遇 · 妖名」。
- **命中反馈**：命中处迸出火花和冲击环；单次 12 点以上的重击有约 90 毫秒的命中停顿、白光和更大的金色伤害数字。你挨打时画面泛红，挨得越重越红。
- **出牌**：打出的牌从手里飞向妖并消失。
- **血条**：掉血时留下一截浅色残影，慢半拍再收回（`parts.tsx` 的通用血条）。
- **走动**：左右转身时镜头带一点侧倾。
- **界面切换**：探索、战斗、狐市、事件、奖励之间淡入切换。

## 限制

- 静态截图看不出动效节奏，需要真人在浏览器里看；未录屏。
- 粒子是平面叠加，不会被墙挡住，也不随镜头移动产生视差。
- 「遭遇」字样会和第一下的伤害数字短暂重叠。
- 评审待安排，未在实体手机上验证性能。
