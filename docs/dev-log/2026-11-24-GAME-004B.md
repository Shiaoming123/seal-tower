## 结论

会卖货的机器人胜率从 50–63% 降到 43–47%，四把兵器相差从 13 个百分点缩到 4。死亡不再集中在一只妖身上。

调参中发现并修了一个老问题：守关妖的血量和伤害倍率从来没有生效。

每项改动、调前调后的数字和没达标的地方都写在 [数值体检](../../v2/docs/数值体检.md)。

## 做了什么

| 部分 | 改动 |
| --- | --- |
| 第一层 | 普通妖血 ×1.3–1.4、伤害 +2～3。纸灯蛾、灯鼠、引魂灯的招式加大。镜狐 ×1.1、+2。灯蛾娘 ×1.15、+3；纸扎娘娘 ×1.1、+1 |
| 第二层 | 普通妖伤害各 +3。夜市狐（守关）×1.05、+1 |
| 第三层 | 普通妖伤害各 +1。精英守门黑狐 ×1.5、+5 → ×1.25、+3；堕道者 +4 → +3 |
| 狐市 | 收货价为货价的 75%（带回镇上仍是全价）。同一种货每多卖一件降 20%，至少 1 石。逐层涨价 15% → 25% |
| 上楼 | 回复已损失气血的 40%（原来 50%），楼梯提示的文字跟着常量走 |
| 修复 | `dungeon.ts` 生成守关时带上 `FLOOR_SPAWNS` 里的 `hp`、`dmg` |
| 卖货说明 | 狐市卖货栏写明「绯绡压价收货，比带回镇上折库银少两三成」 |

新的经济数值都是有名字的常量：`SELL_RATE`、`SELL_GLUT`（`inventory.ts`），`SHOP_INFLATION`、`CLIMB_HEAL`（`run.ts`）。

### 报告本身的改进

- 每只妖按「层 + 类型」分开统计。以前守门黑狐在第三层的普通妖和精英混成一行，致死率显示 10%；拆开后第三层精英是 40%，是当时最大的死因。
- 新增「每层普通妖合计」一表，直接对照目标区间。
- 掉血改为在战后回血（鼠牙坠）之前计算。

## 调参记录

会卖货的机器人，除注明外都是 200 局 × 4 把兵器。

| 步骤 | 胜率（剑 / 盾 / 灯 / 算盘） | 说明 |
| --- | --- | --- |
| 调参前 | 63 / 50 / 63 / 61 | |
| 第一层加伤加血、修守关倍率 | 58 / 47 / 59 / 64 | 100 局。第一层普通妖掉血只升到 2 左右，见下 |
| 第二层普通妖 +3、收货 75% | 44 / 44 / 51 / 46 | |
| 逐层涨价 25% | 43 / 42 / 50 / 40 | |
| 上楼回血 40% | 41 / 39 / 45 / 37 | |
| 拆开统计后发现守门黑狐，减弱它和堕道者 | 48 / 50 / 53 / 45 | 死因分散了，胜率回升 |
| 第三层普通妖 +1（最终） | 44 / 45 / 47 / 43 | |

第一层普通妖加血到 ×1.7 或加伤到 +3，平均掉血都停在 2 左右：机器人见妖要出手就先格挡，起手牌平均有两张「格挡」。第一层普通妖的目标因此改成 2–4，威胁交给第一层精英和守关（掉血 8–9）。

金疮药从 5 石涨到 7 石试过，胜率没变，已撤回。

## 限制

- 胜率仍比目标（30–40%）高 3–7 个百分点。下一步要先看真人：机器人格挡比人准。
- 卖货仍让胜率高 15–30 个百分点。不卖货的机器人一直背着用不上的货，这个对照偏弱，所以以会卖货的胜率为准。
- 第三层精英致死 16–21%，比负钟君（17%）还高。机器人见妖就打，真人可以绕开；玩家是否知道精英可以不打，需要并入 GAME-001 观察。
- 第一层普通妖的威胁没达到原定目标，目标已改。
