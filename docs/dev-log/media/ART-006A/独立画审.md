**局限。** 原有受击亮闪为 `brightness(2.2)`，手机宽度下铜锈和微小崩片细节受亮闪影响。现有出牌投影会短暂掠过腿部；上弦首次提示及上回合的招式横幅会覆盖少量角色画面。[首次提示未关闭时](390/首次上弦提示.jpg) 是专门保留的原屏。

**测试方式。** Chromium 桌面 1280×720 与 390×844 触屏模拟。同一 `gallery` 签从正常入口进塔，开发定位两次楼梯与铜傀所在格，实际点击前进和上楼至第三层，再点击战斗按钮。伤害和全格挡分别设置敌方 0/8 格挡，仍走玩家出牌入口。逐帧记录的首个动作采样已显示相应资源；三个 PNG 与实际加载的 WebP 字节分别匹配导出哈希，两尺寸均无页面错误。实体手机、Safari、自然遇敌频率与重击停帧分支未覆盖。[终稿逐帧记录](实测记录.json) · [改前实测](改前/实测记录.json)
