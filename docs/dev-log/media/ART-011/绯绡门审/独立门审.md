# ART-011 绯绡封面独立门审

**通过 R1。** A 因出现四条尾尖和顶部高亮灯笼退回。B 的构图和三尾保留，R1 补了远侧耳朵并修正了捏钱手。

- **缩略图**　300×400 能读到人物自身右眼闭合、左眼睁开。画面的左眼闭、右眼开，绿色眼睛下留有泪痣。方孔铜钱、搭柜台的手与下方完整狐扣都可辨。 [300×400 无字稿](./300×400无字.png)
- **手与器物**　捏钱左手的食指从铜钱右上压边，拇指从左下托住，三枚内折指尖相连可核。手掌、前臂、宽袖相接。柜台右手可辨四根长指，拇指自然由掌缘与狐扣遮蔽。 [铜钱与五指前后](./铜钱与五指-前后.jpg) · [柜台手与狐扣](./柜台手与狐扣.jpg)
- **角色和构图**　远耳由发髻后探出，两耳均为黑缘红内。额前红宝石金链、花簪流苏、深卷发、红指甲与酒红金纹宽袍对得上。身后三条红白尾各有独立尖端，近尾搭柜边。秤、零钱、红账本和灰包在台面，窗外古塔及暖冷双光支持狐市场景。衣领、体态和机位适合公开展示。 [第二耳前后](./第二耳-前后.jpg)
- **留白和文件**　用项目现有字体试排，标题在顶部 22%，台词与标签在底部 20%，没有压脸、手、铜钱或狐扣。试排独立于交付 PNG，母图不含透明区域、标题、水印或签名。原生 1086×1448 保持 3:4，整幅以最近邻 2×导出至 2172×2896，没有裁切。放大解决交付画布尺寸。 [文字试排](./300×400文字试排.png) · [尺寸与留白](./尺寸与留白.json) · [原图及导出哈希](./导出尺寸和哈希.json)
