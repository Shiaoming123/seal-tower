# ART-014 独立画审

独立视觉评审 Agent 审看桌面和 390×844 的 Chrome 实机图。使用固定库存夹具让同一件物品出现在需要检查的界面。

## 首批门审

白狐尾的横轮廓、灯油壶的竖轮廓可辨。碑拓的拓印纹样在手机上较小。墨粉首图更像矿块，扩大纸包折边并去掉晶体后，与灯灰在形状和颜色上均可分开。复审通过后制作其余十件。[首版手机行囊](gate-before-phone-bag.jpg) · [复审手机行囊](gate-after-phone-bag.jpg)

## 终审 · 十四件通过

- 护身符是黄纸三角形，镇货符是压黄纸的横木牌。红纸、火鼠毛和招财袋分别用叠方、簇形和圆袋轮廓。
- 水珠、磨刀石和铜片虽然都带青色，但轮廓分别是圆珠、长方石和异形铜片。枭羽与碑拓都占竖格，轮廓和主色不同。
- 手机行情牌上的插画主要辅助扫视。细纹需要结合名称或详情阅读。画审只评估实际渲染和辨识度。
