# v2 首批三件美术 · 独立画审

**三件通过。** 引魂灯保住了小尺寸的人脸和魂火，水鬼经修订后能读成淹死的船工，灯鼠货郎的作揖和包袱能直接交代它是来做生意的。已复核 1280×720 与 390×844 两种尺寸的六张交付原屏，也独立在本地 Chromium 从标题进塔，使用开发入口指定遭遇核对实际 WebP。二层桥驿的水鬼由美术预览指定，未测自然随机遇敌率或实体手机。

| 资产 | 独立复核 |
| --- | --- |
| 引魂灯 | 暖纸面、裂缝内的绿火、焦红穗在冷暗底上有清楚的明暗分组，和同屏比例的既有纸灯蛾相配。390 宽仍能辨出灯钩、半张嘴和下方火舌；「吸灯油」与攻击、减油数字在挂钩上方。原图钩顶余量只有约 5 像素，终稿 WebP 已补边，主体距顶 16、距底 17 像素。[桌面](final/1280/lantern-spirit.png) · [390 宽](final/390/lantern-spirit.png) |
| 水鬼 | 初稿的珠簪、饰纹和淡粉指甲更接近女修。终稿改用粗绳束发、补丁粗布、咧口露齿和深色指甲。对着两只摊开的手逐根数，均能看到一根拇指和四根手指；指尖水滴与破袖尖分得开。420×387 的 WebP 实心轮廓四边分别留左 25、上 22、右 24、下 22 像素。390 宽初版的水纹悬在房间上方，终稿落在约 y=500 的低位，脸、指尖、水纹都完整。意图在头上，血条及技能说明在水纹下方，说明和手牌之间仍有间隔。水旋本身是角色画的一部分，场景上部仍留有较大暗色空区。[桌面](final/1280/water-ghost.png) · [390 宽](final/390/water-ghost.png) |
| 灯鼠货郎 | 暖光落在斗笠、脸和靠前的手上，冷绿衣袍与补缀包袱能分层。抓口的陶罐与卷货在实际事件图中可辨。可从两袖追到两腕，掌指相覆形成作揖；后掌被盖住的指头无法逐根计数。桌面插画与选项并列，390 竖排，耳尖、卷尾和双脚均完整，四个选项可读。[桌面](final/1280/ratpeddler.png) · [390 宽](final/390/ratpeddler.png) |
