**重击补测。** 棘碑与夜枭两尺寸另设玩家力量 8，比普通斩多 8 点。实际点击「斩」扣去各 14 点。重击停顿与之后的受击均使用专用图，四条轨迹各 14 个停顿采样与后续帧均未出现错图。[棘碑重击](thorn-stele/390/heavy-95.jpg) · [夜枭重击](night-owl/390/heavy-95.jpg)

**局限。** 一般受击亮闪会冲淡细小崩片，重击亮闪更强；两怪以缩枝或抱翼的大轮廓区分受击。夜枭同位远处有一件原生地图物件，和脚下背景重叠，未伸入贴图轮廓。夜枭出招母图左缘约有 22 个 `α=1` 像素，运行图左侧实色从 x=23 起，无法在实机辨认外缘孤点。桌面的提示信息高度变化会改变视图框；这一变化在旧图基线一致，390 的三只在动作前后回到同一个框。

**复现。** Chromium 1280×720 和 390×844 触屏模拟，从正常入口用 `gallery` 签进塔。开发定位把两次楼梯和对手放置在相邻空格，实际点击前进、上楼与出牌，三怪战斗所处地格同为 (7,10)。普通扣血之前将敌人设为 0 格挡。缺少「斩」时替换第一张为原始卡；设定测试数据之后仍执行游戏按钮。所有三个 ID 的三个姿态都核对了实际请求 WebP 与 PNG 母图 SHA256。普通动作首个采样已显示相应图，动作结束回到主图，两尺寸无页面错误。用隔离浏览器清除新姿态的资源映射得到同站位旧图对照，未改游戏项目。实体手机、Safari 和自然遇敌频率未覆盖。[棘碑旧图基线](改前/thorn-stele/实测记录.json) · [夜枭旧图基线](改前/night-owl/实测记录.json)
