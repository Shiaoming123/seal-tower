**返工复验。** 合入 UI-002 后的第一次取样里，守关妖的脸在 1280 被 HUD 压住，假狐商在 390 从镜头里消失。修复后两种情形都能看到完整主体，第一回合后血量和下一招跟随战斗状态更新，玩家和敌方逻辑格在换回合时未移动。[修复前纸扎娘娘](修复前-纸扎娘娘-1280.jpg) · [修复前假狐商](修复前-假狐商-390.jpg)

**后续工程项。** 这次的桌面假狐战中，整张图实心轮廓约 191×241 像素，390 模拟约 262×331。取景会随可退空间和视口变化，桌面远距离仍主要靠狐尾辨识，币和指尖以近景或母图为准。另做二阶段复验，把娘娘起始血量设为 32 后实际点「斩」，恢复到 38，叠 10 格挡、2 力量，下一招更新为 11。390 中央瞬时文字两端超屏，上方数值仍可读。堕道首座的七剑和提示也做了静态回归。[二阶段](390/paper-matron-phase2.jpg) · [堕道首座回归](390/fallen-elder-guard.jpg) · [补充验证数据](补充回归.json)

**边界和限制。** 通过 Chromium 桌面和触屏模拟，从镇灯铺进塔，用 gallery 签、测试楼梯或前格的事件测试位进行重放。事件用实际前进和鼠标点击或触屏触发，买、走两个分支分别扣 8 或 0 石，维持近景并回到探索。撤退在自然进入同一格的这条测试路线退回前一格，其他地图布局未覆盖。四张 PNG 母图与运行图按清单匹配哈希，四边均不存在 α≥128 像素接边。实体手机、Safari 和自然随机遇敌未覆盖。
