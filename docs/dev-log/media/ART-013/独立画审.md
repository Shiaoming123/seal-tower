# ART-013 独立画审

独立视觉 Agent 审看正常游戏流程在 Chrome 渲染的截图。画审记录的是视觉表现，[点击、触摸与资源验证](离线验证.json)另有实机脚本。

## 首批门审与返工

- 货紧、雨夜、香火旺的主体和规则在 390×664 都完整可见。
- 精英巡夜首版退回，画框裁去守夜人头部。拉远后，头部、躯干和提灯同时入画。手机上以剪影辨认人物，桌面更清楚。复审后首批四张放行。[首版](patrol-rejected-phone-short.jpg) · [390 修订版](patrol-phone-short.jpg) · [桌面修订版](patrol-desktop.jpg)
