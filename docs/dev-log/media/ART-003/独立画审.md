# ART-003 独立画审

**火鼠待机、火鼠扑击、碑灵和翻倒的货车均通过。** 在相同桥驿机位，火鼠的焦红鬃毛与火尾、碑灵的石臂与裂纹能够直接辨认。两种屏幕均使用游戏实际渲染。[同机位前后对照](同机位前后对照.jpg) · [请求哈希、轮廓尺寸和逐帧记录](实测记录.json)

| 资源 | 返工与实机复核 |
| --- | --- |
| 火鼠待机 | 焦红背鬃、缺角耳、带火的环尾区别于原来的灯鼠染色图。初版方形画幅让 390 宽的可见轮廓只有约 127×107。两姿态改用同一裁框，导出均为 320×276，待机可见尺寸约 148×125，爪尖与名字之间仍留有空隙。三条可见腿的落点清楚，第 4 条被身体挡住。[1280 原屏](1280/fire-rat.jpg) · [390 原屏](390/fire-rat.jpg) |
| 火鼠扑击 | 保持缺角耳、尾尖和三缕火星，张口并把前爪探近镜头。真实点击「结束回合」后，第一动作帧已载入新 WebP，经过约 260ms 恢复待机，采样未发现空帧。390 宽在 125ms 的可见轮廓约 142×123，缩势时与待机体量接近。现有位移动画快结束时，前爪短暂掠过名字上缘，HP、招式和取材文字可读。[1280 原屏](1280/fire-rat-attack.jpg) · [390 原屏](390/fire-rat-attack.jpg) · [248ms 前爪位置](390/fire-rat-attack-248ms.jpg) |
| 碑灵 | 旧图的浅色立碑改成青黑碑体。石臂、分立的石脚和金光裂缝在 390 宽约 132×142 的可见轮廓中仍清楚，可和带荆棘的同类分开。小型符纹仅在大图易辨，实机靠碑形、石臂和金缝识别。[1280 原屏](1280/stele-spirit.jpg) · [390 原屏](390/stele-spirit.jpg) · [棘碑对照](390/thorn-stele.jpg) |
| 翻倒的货车 | 第一透明稿的货车带破车辕、散布匹、瓷坛与麻袋，但轮子近垂直，车厢更像停在坡上。终稿露出底轴，抬起轮面并让车厢侧躺。390 宽时图形约 230×214，断辕、瓷罐和布匹可辨，最低处与事件纸面相距约 83px，三组选项完整可点。[1280 原屏](1280/event-cart.jpg) · [390 原屏](390/event-cart.jpg) |

**验证方式。** 在 Chromium 1280×720 桌面和 390×844 触屏模拟中，从镇灯铺进塔，借助指定楼梯站位以正常按钮进入第二层，并用开发入口指定遭遇。战斗首回合正常输入，记录实际换图与恢复。另在下一回合真实操作后暂停 CSS 125ms 取得可重复的动作原屏，248ms 照片用于检查信息覆盖。事件用面板按钮退出并回到探索。10 张原屏及两张动作后段补帧未见运行异常。四件新图在两种视口的实际请求哈希均与导出清单相符。实体移动设备、Safari 和随机出场未验证。
