## 重放和证据

Chrome 桌面为 1280×720，触屏仿真为 390×844。两种尺寸都从镇灯铺开始，以固定 **gallery** 签进入塔内，走到相邻测试楼梯，再以正常按钮操作登上二层和三层。敌怪设在三层同一个前方格，实际按「前进」开战。终稿与占位对照都用合入 UI-003 后的渲染器，并待遭遇文字淡出。占位对照仅在浏览器内按地址替换为 Git 提交 `18e9997` 中原始三个 WebP；参考组则使用相同机位展示碑灵、负钟君第二形态、灯蛾娘。全程未修改玩法代码或仓库文件。

两种视口中，三张新图的实际 WebP 请求哈希和母图哈希均与导出清单相符，没有页面异常。几何尺寸为透明度至少 128 的可见区域估计，呼吸和悬浮会有轻微浮动。自然遇敌概率、实体手机与 Safari 未覆盖。 [终稿实测记录](实测记录.json) · [占位与参照实测记录](占位与参照记录.json)
