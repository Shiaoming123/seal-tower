# ART-009 独立实机画审

**结论：49 张通过。** 五组牌在 1280×720 桌面与 390×844 模拟触屏的实际战斗手牌中均正常加载。烧尽、剑气纵横、以货挡灾和挑材的返修终稿均从实际可点的牌位复验。

## 实机怎么走

同签 `gallery`，在正常入口接单，用木挡板走到第一层纸灯蛾。用两个隔离测试档把战斗手牌换成待审牌，等发牌动画与图像加载完成再取帧。强遮位测试另在该测试战斗加入灯灰、灯芯及 4 层敌方灼烧，查看资源牌可用时的画面。首批斩、架、盾击、扬灰另外来自自然抽牌，并实际点击出牌。未测实体手机。

两视口分别覆盖全部 49 张。另有 12 扇实机并排检查易混牌形，四张修订分别在两种视口移到五张牌最左槽并实际点击。浏览器响应、运行文件、导出清单与母图的 SHA-256 对得上。图框完整显示时分别为 109.78×54.89 和 71.36×35.68 CSS px。最挤槽的最低可见采样比例为桌面 92.16% 与窄屏 66.20%，样本中未见自裁或超出视口。桌面可悬停看全，模拟触屏点击即出牌。

|---|---|---|
