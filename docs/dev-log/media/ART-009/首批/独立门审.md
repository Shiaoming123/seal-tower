## 原屏尺寸与遮挡

四张 WebP 均为 256×128。桌面默认手牌中，新图旋转前的实际内容约 109.78×54.89 CSS 像素，实体采样可见 92.54%–92.90%，鼠标悬停约 122.95×61.48 像素且完整显示。390 触屏实际内容约 71.36×35.68 像素。相同的五张默认手牌里，左槽、次槽或中槽目标可见 66.55%–66.87%，余下约三分之一由邻牌遮挡。新图在卡面画框内，也未超出视口。对照旧借图时，部分竖形道具在桌面悬停后仍会被画框裁掉。

轻触会直接打出牌，玩家只能在短暂的飞牌阶段看到展开图。当前 390 牌扇还可能压住左槽牌名的末字，画面识别需优先放在中心偏左。此项保留为既有 UI 记录。已核对新卡图的浏览器 WebP、仓库文件与母图哈希，飞牌实际源与手牌一致，所有场次无页面脚本错误。

## 对照口径

旧图以隔离浏览器撤去四个新映射的方式复现，分别读到剑、铜镜、铜镜和灯灰。遮挡采样取贴图 α≥128 的点，按实战牌的 CSS 缩放和旋转投影，用浏览器命中检测区分邻牌覆盖、卡图窗口自身剪裁及出界。390 为 Chromium 触屏模拟。
