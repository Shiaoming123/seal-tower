# ART-002 独立画审

**纸人童、墨蛾、灯神龛通过本轮美术验收。** 390 宽时，纸人童的双刃、墨蛾的砚腹、神龛的灯火都能从剪影中辨认。三张游戏贴图的实际请求字节与导出清单相符。[同机位占位与终稿](三件占位与终稿.jpg) · [实测记录](实测记录.json)

| 资源 | 从母图到实机的复核 |
| --- | --- |
| 纸人童 | 纸脸中折、胭脂点、袖口剪孔及右袖破口中的竹篾，把纸扎材质交代清楚。初稿的握处像单个白环，第二稿画面左拳少一道分指折痕。终稿两拳各有四块可数的卷指，加上一根单独的拇指压住红纸刀根。两刀顺着夹握角度向外伸，尖端完整。390 战斗画面可读出双刃与「纸刃」连击意图；逐指数目在原图放大后复核。[初稿双手](纸人初稿双手.jpg) · [终稿双手](纸人终稿双手.jpg) · [1280 原屏](1280/paper-doll.jpg) · [390 原屏](390/paper-doll.jpg) |
| 墨蛾 | 在暖亮底和游戏暗底上分别检查透明轮廓，四片撕裂纸翼留有透空，深蓝墨脉与飞白、洒金相配。笔锋正对腹部砚池。初次方形导出在上下空了约 63 像素，390 宽时，蛾的实心轮廓只有约 128×92。终稿收边至 320×238，实机约 183×130，与纸灯蛾体量相近，砚口及双翼轮廓更清楚。黑墨滴在手机上很小，吐墨意图和数值仍可读。[1280 原屏](1280/ink-moth.jpg) · [390 原屏](390/ink-moth.jpg) |
| 灯神龛 | 候选的两片红带已换成贴柱残墨对联，终稿在木框两侧和双脚下面补入灰石。左边油灯、右边捧灯老人、前方香炉与供钱有前后层次。最细的旧墨与钱孔须放大看，手机上主光源和神像仍能分辨。石唇托住木脚，作为事件插图可以成立；背景仍采用通用街景，墙面没有延伸到整个场景。两种尺寸的供奉选项都完整可读。[1280 原屏](1280/oilshrine.jpg) · [390 原屏](390/oilshrine.jpg) |

**验证方式。** 在独立工作树开发入口 `127.0.0.1:5178` 进入镇灯铺、进塔，再用项目的开发预览指定第一层纸人童、第二层墨蛾和灯神龛事件。两种视口为 Chromium 桌面 1280×720、触屏仿真 390×844。归档为六张实际游戏原屏，以及从透明母图裁出的握刃局部；采样期间未记录到页面异常。本轮未测实体手机、Safari 或正常游玩中的随机遇见概率。
