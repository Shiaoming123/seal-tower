# ART-010 首批四件法宝独立画审

首批通过。狐扣针、封口锦囊、万宝囊、蛾丝扇均使用各自的图像。旧版两个锦囊在狐市、奖励和持有栏用同一个 `pouch`，与同画面养元丹的图像也相同。终稿的封口锦囊细长、束口带金符，万宝囊低阔、袋口露金。390 节省空间的顶栏仍能用两者轮廓辨认。图鉴蒙黑后也能直观看出一高一矮。

| 实机位置 | 桌面 1280×720 | 390×844 模拟触屏 |
|---|---:|---:|
| 狐市货架 | 44 px | 28.6 px |
| 三选一 | 40 px | 26 px |
| 宝箱单件 | 64 px | 41.6 px |
| 已持有栏 | 34 px | 22.1 px |
| 图鉴列表／详情 | 80／110 px | 52／71.5 px |

同签 `gallery`，两个隔离浏览器档案从接单板正常进塔，走 8 步进实际狐市。店中固定四件报价和 80 石来重现实机同柜。实际点买狐扣针和封口锦囊，结算 80 → 30 石，两个货位都变已售且登记图鉴。测试档用开发定位到现有宝箱的邻格，再点前进入箱。把奖励固定为三选一和单件两种呈现，实际选万宝囊，再拿走蛾丝扇。20 格满包（19 个物品实例）在两次领取前后保持原 UID，法宝在持有栏追加。蛾丝扇只出现在未领取选项时仍显示「？？？」剪影，点开无详情。拿走后才出现彩色列表项与详情。用开发导航打开标题，图鉴本身由玩家点击进入。

狐扣针的长杠与尖端、蛾丝扇圆面蛾纹与短柄在 26–29 px 可辨。22.1 px 深色栏优先靠斜长针、细高囊、扁阔囊和短柄圆扇的外轮廓。狐扣针的头部纹饰和蛾丝扇内细纹在该最小尺寸退到次要，在图鉴详情可读取。四件实机图像的响应哈希与运行文件、导出清单和图源匹配，均有透明边。未测实体手机。
