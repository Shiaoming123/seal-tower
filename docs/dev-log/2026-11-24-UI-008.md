## 为什么

用户 11-24 实际游玩后提了四点：

- 战斗结算页「左对齐感觉很杂乱，没有拟物或商业游戏的精致感，就是简单的 UI 页面堆叠」。
- 右边冒出白色的系统滚动条，最下面的侧袋被截在框外。[改前截图](assets/UI-008-reward-before.webp)
- 结算页点物品看不到信息。
- 选东西点一下就直接确认了，希望有二次确认。

## 做了什么

### 结算页重排

不加新美术，装饰全部用 CSS 画，配色沿用现有的金边和暗红。

| 部分 | 改前 | 改后 |
| --- | --- | --- |
| 标题 | 左上角一行字 | 居中的红底匾额，上下金线，两侧纹饰线渐隐；精英和守关的字更亮 |
| 石和掉落 | 一行「+6 石」、一行「掉落：」加小图标 | 居中一排战利品格：石是一枚金色铜钱，货物各占一格，按价值分三档：普通、蓝光（5 石以上）、金光（9 石以上，带呼吸光）。依次弹入 |
| 取材结果 | 一行黄字 | 居中彩带，成功（取材、追回、淬炼）是金色，失败是暗色 |
| 行囊 | 格子、套装、侧袋从上到下堆在左边，侧袋被截 | 有框的托盘，标题居中；格子和套装、侧袋左右并排，侧袋完整可见 |
| 学一招 | 卡牌和「不学」 | 标题居中带小注；选中的牌抬起、加金边 |
| 滚动条 | 系统白色 | 全局换成细的金棕色滚动条 |

[桌面改后](assets/UI-008-reward-desktop.jpg)。竖屏顺序是匾额和战利品、学一招和「继续」、行囊，整页可以滚动。竖屏网格行用 `max-content`，避免 UI-006 那种区块被压扁的问题。[390 宽](assets/UI-008-reward-390.jpg)

### 物品浮窗

行囊组件新增 `details="popover"`：点物品，详情卡就贴着格子弹出，内容和行囊界面里的详情完全一样（说明、受到的加成、套装，以及用、旋转、放进侧袋、拿出来这些按钮）。

- 有关闭按钮；点格子外面也会收起。
- 桌面弹在格子右边，与物品同一高度；竖屏弹在物品正下方、居中。
- [桌面](assets/UI-008-item-popover.png) · [390 宽](assets/UI-008-popover-390.jpg)

选了浮窗而不是右侧固定信息区，原因是右侧已经放着学一招的卡牌，手机上也没有右侧。

### 二次确认

| 地方 | 第一下 | 第二下 |
| --- | --- | --- |
| 结算页学牌 | 选中，牌抬起；下面出现「学『某某』」 | 再点这张牌，或点确认按钮，才学会 |
| 结算页选法宝 | 选中高亮；出现「拿走『某某』」 | 同上 |
| 狐市买牌、装备、杂货、法宝、灯油、删牌 | 商品亮起，上方标出「再点一下买下」 | 才付钱 |
| 狐市卖货、侧袋卖货 | 显示「卖?N」并提示价格 | 才卖出（原来只有装备要点两下） |

点空白处会取消。只有一件法宝时的「拿走」按钮本身就是明确的确认，没改。[学牌二次确认](assets/UI-008-card-pick.jpg)
