2026-11-24 · Codex。用户要求后续协作者能沿文档和素材逐层查阅、复现和交接。

[开发导航](../开发导航.md) 提供版本、任务、实体定义、素材来源及历史记录入口。[协作规范](../Agent协作规范.md) 规定新任务的可检查关系。日志只引用任务 ID、实体 ID、素材 ID、基线和相对证据路径，负责人和导出哈希各自仍以原台账为准。

- 首批回填 ART-007A 到 D，后续素材与日志同批入库。归属检查覆盖版本控制内的开发文档、资产和归档，历史按目录留存，尚未逐份回填实体关系。[资料索引](../资料索引.json)
- 从 `v2/` 运行 `npm run docs:check -- --base origin/main`。曾故意先检查未登记任务关系的六个动作，检查正确报出母图及 WebP 缺链。补上 ART-007D 的日志和证据链接后，检查通过，识别 963 项资料、四条任务关系和 53 组导出哈希。
- [检查器](../../v2/scripts/check-doc-trace.mjs) 检查导航入口、登记的相对证据路径、实际游戏实体、素材是否进入运行目录，以及母图和导出 SHA-256。历史正文里的每处外部链接和截图仍以原归档为准。
