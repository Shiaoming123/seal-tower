# ART-007C 负钟君姿态生产记录

游戏数据 `v2/src/data/enemies.ts` 以气血半值切换到 `bell-heavy`。一期摇铃、铃震与钟落共用发力帧，保留完整铜钟壳。二期「撞碎外壳，露出里面的铜身」由角色图兑现。二期沿用原版高举粗链和双脚稳住的矮姿态，给钟壳右前侧做连续的缺口，露出里面的铜肩及肋片。各阶段保持双龙吊钮、眼下长灰须、青铜环铠、关节与挂链。所有光晕、命中与地面投影由游戏反馈层控制。

使用内置 ImageGen 编辑现有游戏素材。交付为同一 1254×1254 画幅的原生 RGBA PNG；保留原 alpha，复制后以 SHA-256 对照。α≥16 用于排除较透明的生成余量后测量可见范围，并不等同真实场景中的像素颜色差。浅尾差异通过深棕底合成查看。这份证据只是素材在目标展示宽度的对照，独立画审需以实际站位确认动作峰值、受击动效、HUD 和落地感。

## 第一期

一期待机去除旧柔棕底并维持钟形、正向凝视和手脚。攻击将钟壳前顶并压链向前，泛用的一帧能读作钟与重链同时发力。受击偏后仰，掌抬向脸侧，巨钟倾斜仍保持全壳。390 像素画幅中的底边差约 2.5 像素。测试角度内未见截断或明显混色。攻击前链末端仅 6 源像素横向留空，实际扑进峰值应结合 390 模拟核查；预留横边时让脚底维持同一画幅位置。

合成预览按旧待机、新待机、攻击、受击排列。

## 第二期

二期的半边铜钟象征铠甲破损，三张始终给右肩和肋片留出完整识别窗。画面右方是踩近处的脚，受击和出招保持近脚在同一底位。出招让粗链从高位落下，近景的大铜环、前冲的脸和破壳同时可见；受击让链绳在膝边收拢，扭肩后仰，另一手握拳。二期 390 像素画幅中的 α≥16 可见底边差约 3.1 像素。轮廓没有明显缺失。新二期待机的迈步方向有变化，原二期旧图是左脚贴近，重画后右脚贴近，形成切阶段时的换步；正视机位和地平线沿用旧图。请独立画审确认这一换步在实际过半血时像一次踏步而非偏移。

## 量化检查

缩到 390 像素时，第一期攻／受击与待机相差最多 2.5 px 的底边，第二期为 3.1 px。两张攻击的可见左边分别有 6 与 17 源像素留空。若实机图像盒宽达 366 px，CSS 扑进到 1.22 倍后，横幅需额外释放约 8%–9% 的左右空间以显露链环；视觉验收优先使用游戏实测。原图不强行二次变形，可由现有导入器按实盘确定是否同时调整两阶段的攻击横向留边。
