# ART-007F 引魂灯

两帧以已导入的 `v2/src/assets/lantern-spirit.webp` 为 ImageGen 编辑输入。既有待机的尺寸和 3D 投影不动。左列原待机、中列吸灯油、右列受击，上排用项目 `docs/dev-log/assets/UI-001-walking-desktop.jpg` 的照影廊窗格和墙面截取作为材质对照，下排 128 像素暗底。预览 `review-lantern-spirit.png` 仅用于画审，尚未通过游戏播放验证。

| 源图 | 验收特征 | α ≥ 128 主体边界，像素 |
| --- | --- | --- |
| 旧待机，277×300 | 黄纸内的鬼脸，带锈铜骨架与钩，底部红穗和绿焰 | (60,16)～(214,282) |
| `lantern-spirit-attack.png` | 球体下俯，吸灯油时纸嘴完全张开，红穗展开，绿焰仍在灯底固定位 | (191,90)～(1065,1070) |
| `lantern-spirit-hurt.png` | 灯钩随球偏，纸眼收紧，短嘴与朝左的红穗区分攻击 | (209,69)～(1000,1089) |

两帧 RGBA、1254×1254，四角 α0、主体不触原边。两帧共享左 102、上 20、宽 1052、高 1140 输入画幅，输出约 277×300。保留灯底悬垂最低点在输出约 y=276、281（原 y=282），避免因为裁去红穗而令灯体跳大。源图本身已留边，切勿再次叠加出口的安全边。攻击与受击撕缝的绿色强度低于原图，暗底仍可区分；烘焙光、地面影和环境尘均无。现有 `Combat.tsx` 通用姿态选择会在敌人冲刺时使用同一出招帧，吸油是这张画面的设计依据。不同招式的粒子应由游戏层处理。
