2026-11-25 · Codex 制作、导入与走查，独立画审 Agent 首审、返工复审与终审。替换红纸等九件货物和五件配件的改色占位，原资源 ID、格形和数值沿用。水珠和裂水珠继续共享一张图，通过原有暗化样式区分。美术清单的 14 个改色占位归零。

## 首批与终审

先将墨粉、碑拓、白狐尾、灯油壶放入行囊和狐市。墨粉首图像矿石，按独立画审改成摊开的蓝灰折纸包。复审确认和灯灰可分后，补齐其余十件。终审确认相近颜色的道具能靠轮廓区分。狐市行情牌的小图仅适合看轮廓和色块。[独立画审与截图](media/ART-014/独立画审.md)

## 验收与出处

- 同一批物品载入离线游戏，核对桌面 1280×720、390×844 触屏模拟的行囊、卖货格、行情牌和装备栏。首件进入狐市的库存与行囊内容由固定测试夹具指定。该检查验证实际画面与资源，不代表一局自然掉齐这些货物。[离线实测](media/ART-014/离线验证.json)
- 两视口中 14 张均成功解码，内嵌图的 SHA-256 与导出记录一致，无页面错误。背包形态检查覆盖 41 种物品的适用旋转，空格误读、溢出和选中配件遮挡均为零。修正该旧检查在 Windows 下拼出双盘符的问题。
- 离线构建通过。单测 113 通过、2 跳过。实体手机、线上包未复验。
- 采用 256 像素长边的透明 PNG 母图与 128 像素长边的 WebP。1×1 为正方，1×2 和 2×1 分别使用竖、横画幅。运行图合计 64,894 字节。[首批提示](assets/ART-014/生成提示-首批.md) · [余批提示](assets/ART-014/生成提示-余批.md) · [归一化和来源](assets/ART-014/归一化.json) · [导出哈希](../../v2/art/exports.json)

在 `v2/` 执行 `npm run build:offline` 后，运行 `node tests/goods-art-view-check.mjs .cache/goods-art-view offline` 可重放截图和资源校验。
