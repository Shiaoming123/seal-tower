## 为什么

UI-007 手机走查时发现：竖版舞台 600 宽，在 390 宽的手机上要缩到 0.65 倍，委托卡这类小字实际只有 9–10 像素。当时要改所有竖屏布局、风险大，没有动。QA-001 之后全界面检查能抓到区块挤压、文字溢出和点不到的按钮，可以放心改了。

## 做了什么

- 竖版舞台宽度 600 → 540。390 宽的手机上缩放从 0.65 提到 0.72，所有文字和按钮放大约 11%。
- 舞台高度范围 1000–1400 → 880–1260。原来最低 1000 高，在 390×664 上会变成按高度缩放，字反而不会变大；改后由宽度决定缩放（390×664 时舞台 540×919）。
- 竖屏行囊弹窗 576 → 516 宽，比舞台窄。
- 收窄后全界面检查报出两处，已修：
  - 镇灯铺「营建铺子」：营建卡一排 4 张，最后一张的按钮被挤出舞台 16 像素，点不到。竖屏改为一排 2 张。
  - 战斗：5 张手牌摊开比舞台宽，最右边牌角被裁 3 像素。竖屏手牌叠得更紧一些。

- 镇灯铺顶栏的「库银」在 540 宽时换到第二行，不算溢出，没改。
- 没有真机验证字号是否够大。
