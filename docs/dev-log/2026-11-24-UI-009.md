## 为什么

用户实际游玩后提出：出牌前希望看到这张牌会造成多少伤害、什么类型；希望有暂停按钮，能重新开战；探索时也没有暂停、存档、回主菜单的入口；还希望 combo 联动、出牌和格挡都有音画反馈。

## 做了什么

### 伤害预览

- `simulatePlay`（`combat.ts`）：把当前战斗状态完整复制一份，在副本上真的打出这张牌，统计伤害、段数、被格挡吃掉的量、格挡、回血、对敌人施加的状态、是否打断蓄力、是否打碎部件、能否打死。预览和实际结果一致，蓄势、套装、虚弱、易伤、怕火、多段都自动算对。
- 电脑：鼠标移到手牌上就显示。手机：点牌放大时显示（UI-005 的两步出牌）。
- 显示方式：敌人血条末端闪出这张牌要扣掉的那段；血条下一行写「-10 · 2 段」，加上「怕火 · 伤害翻倍」「格挡吃掉 3」「打断蓄力」「会打碎颈扣」「灼烧 +3」等标签；能打死时有金色「致命」。格挡牌在玩家这边显示「+5 格挡 → 全挡住 / 还会挨 N」。[预览](assets/UI-009-preview.png)

### 暂停菜单

- 顶栏新增「菜单」按钮，电脑按 Esc 也能打开（自动行走中按 Esc 仍是先停下）。
- 内容：继续、存档并回主菜单、声音；战斗中多一项「重新开战」。[探索中的菜单](assets/UI-009-pause.jpg)
- 重新开战：进战斗时在内存里留一份状态快照（含随机数状态，所以手牌一样），点两下回到第一回合。刷新页面后快照就没了，这时不显示这一项。
- 存档并回主菜单：游戏每一步都自动存档，回标题后点「继续上一趟」接着玩。也要点两下。

### 连击与音效

| 时刻 | 反馈 |
| --- | --- |
| 打出技法牌 | 加一声木鱼 |
| 打出心法牌 | 两声低沉的古琴 |
| 获得格挡 | 新的「举盾」闷响 |
| 敌人一击被完全挡住 | 浮出「全挡住！」，清脆的金属声，蓝色闪光（原来只有「挡住 N」） |
| 同一回合第 2、3… 张攻击牌 | 浮出「连击 ×N」，琵琶音一次比一次高 |
| 火系牌打怕火的妖 | 浮出「怕火！」 |

新音效（`guard`、`parry`、`combo`、`power`）都用现有的合成音色拼成，没有加音频文件。

## 验证

| 检查 | 结果 |
| --- | --- |
| 浏览器 | 书虱战斗：悬停「连斩」显示「-10 · 2 段」和血条预扣（4×2，刃套装每下 +1）；实际出牌后血量 34 → 24；战斗中打开菜单，「重新开战」第一下只变成确认文字，第二下回到 34 血、5 张手牌 |
