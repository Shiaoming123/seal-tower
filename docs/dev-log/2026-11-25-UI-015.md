2026-11-25 · Codex · 首屏沿用照影廊月夜原图、斩妖人立绘和书法标题。廊灯的暖光、贴地的冷雾和暗角按不同图层加入。保留主角的位置与比例。暖光和薄雾用低幅度 CSS 动效，系统开启「减少动态效果」时使用静态光影。

## 入口与视觉复看

朱漆主入口在无存档时是「去镇灯铺接单」，有存档时是「继续上一趟」。每日签和重新接单次之。音量、帮助、成就和图鉴保持独立可点击。390 宽手机的主按钮约 45 CSS 像素高。缩短短屏菜单的纵向间距，给原立绘头部留出空间，并提高统计文字对比度。

独立视觉 Agent 对照改前、改后首屏，复看窄屏和短屏有存档状态，确认主视觉完整、入口层次更明显。短屏在有存档且展示每日记录时，统计文字仍靠近发髻，但未遮住主角。最终将继续入口上的气血、层数改用正文楷体。

## 验证

- Chrome 离线构建实测桌面 1280×720、390×844、390×664 和 320×568。对照无存档、有存档和当日有记录，按钮均在可见区域内。手机入口逐项点过，最小检测目标短边至少 24 CSS 像素。首次 Tab 聚焦主入口且提示线可见。
- 音量设置面板、帮助、成就、图鉴、每日签、接单进塔和继续原种子均通过。测试通过一次实际开局生成存档，并填入每日记录覆盖较长文案。减少动态效果模式中的两层持续动画均关闭。[离线验证](media/UI-015/离线验证.json)
- 单测 113 通过、2 跳过。普通与离线构建通过。手机尺寸为浏览器模拟，验收记录对应本地包。
