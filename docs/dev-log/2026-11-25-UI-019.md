战斗左下角可查看抽牌堆、弃牌堆和消耗牌堆。按钮持续显示张数，空堆也能打开。牌堆窗口直接切换三种牌堆，牌面包含升级与装备加成。抽牌堆按牌种展示，弃牌和消耗牌从最近打出的一张开始展示。

打开窗口不会出牌或结束回合。关闭后恢复战斗输入。手机留出一排按钮的高度，牌堆窗口单独滚动，关闭按钮留在顶部。顺手修复数字快捷键按到空手牌位时的异常。

## 验收

- 使用 47 号路签进入灯鼠战斗，指定手牌验证两种实际去向。桌面 1280×720 和 390×844 Chrome 触屏模拟均验证空堆、有牌、18 张牌滚动、升级和加成、出牌后数量变化、弃牌回洗、快捷键隔离、关闭后继续出牌及离战自动关闭。实体手机未检查。[浏览器回归](../../v2/tests/combat-piles-check.mjs)
- 独立复审核对了战斗离开时清理遮罩、操作隔离与恢复、抽牌堆顺序及桌面和 390 宽实机截图，无阻断问题。复审以源码和回归证据为基础。
