# UI-002 战斗留在场景里：妖站在地图上

2026-11-23 · Claude（工程）· 分支 `claude/ui-002` · 起始提交 `e245864`

## 问题

用户反馈「敌怪的位置并没有正常出现在地图上」。原来走进妖所在的格子才开战，战斗时场景里的妖被隐藏，换成一张浮在屏幕上方的平面图，脚不着地、大小和走廊对不上（ART-001 曾为此给水鬼单独写竖屏偏移）。

## 做法（参考《吸血鬼爬行者》）

- **在妖的前一格开战。** 往妖的方向走（或自动行走到它），会停在它面前一格、转向它，战斗就地开始。前方提示写「再往前一步就开战」。（`Explore.tsx`）
- **妖留在场景里。** 渲染器新增 `project()`，算出某一格上的立像在屏幕上的位置和大小，和走廊里的立像画法一致。战斗层把高清原画放在这个位置，脚踩在地面上；渲染器只画它的接地阴影（`shadowOnly`）。画面每帧重新对齐，镜头移动、窗口缩放都跟得上。（`raycaster.ts`、`Combat.tsx`）
- **镜头取景。** 战斗时镜头后退一点、略低头，让整只妖站在手牌上方；身后是空地时大型守关妖退得更远，身后是墙就不退，避免镜头进墙。
- **会飞的妖**（纸灯蛾、墨蛾、灯蛾娘、引魂灯、夜枭）离地悬浮、轻轻上下飘，阴影更小更淡。
- **场景光照**：妖的亮度随距离和灯油变化，和走廊同一套光。
- **头顶信息**（意图、名字、血条、状态、取材、意图说明）放在妖头顶，超出屏幕时压在立像上方而不出界。伤害数字和刀光跟着妖的实际位置。
- ART-001 的水鬼竖屏专用样式已删除（按台账交接），`data-enemy` 属性保留。
- 开发入口 `__seal.fight()` 改为把妖放在面前一格；`tests/gallery.mjs` 每次清掉上一只测试妖，避免残影。
