## 结论

做了一份能反复跑的模拟报告：每只妖的回合数、掉血和致死率，每层的收入和花销，灯油耗尽率，卡牌选中率。

报告发现以前的模拟漏掉了跑商：机器人从不卖货、不买法宝。补上以后，随手打的胜率是 50–63%，偏简单。第一层普通妖几乎不造成掉血，离开第三层时平均还剩 171 石。

这一期**只建工具、定目标，没有改游戏数值**。调参登记为 GAME-004B。目标区间和下一步见 [数值体检](../../v2/docs/数值体检.md)。

## 做了什么

- `v2/tests/bot.ts`：
  - 机器人在狐市卖掉委托用不上的货（引灯盘留 3 份灯灰）。
  - 钱比法宝贵 25 石以上时买法宝。
  - 可选的 `SimStats` 收集器，记录上面那些数字。
  - `playRun(run, { sell: false })` 可以关掉卖货做对比。
- `v2/tests/report.test.ts`：只在 `REPORT=1` 时运行，平时 `npm test` 跳过。生成 [report.md](../../v2/docs/sim/report.md)（会卖货）和 [report-nosell.md](../../v2/docs/sim/report-nosell.md)（不卖货）。
- `v2/docs/数值体检.md`：怎么跑、目标区间、看到的问题、下一步调参顺序。
- `docs/资料索引.json`：把三份新文档归入 v2-design，并加入 `mechanic:balance` 的定义入口。
