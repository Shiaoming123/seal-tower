2026-11-25 · Codex · 鼠标坐标、落格高亮和松手使用一致的抓取锚点。拖影渲染到整个舞台的顶层，避开带平移和缩放的入场面板。拖大件时抓住哪一格就按哪一格对齐，按 R 会同时旋转拖影与落格。

## 复现与顺手修正

- 1024×740 的 Chrome 视口将行囊入场动效定格在 180 毫秒。改前指针在 (320, 397)，拖影中心偏右 167.9、偏下 12.9 CSS 像素。改后同条件误差不足 1 像素。
- 同类问题包括整叠可以合并却标红，以及取消后仍留着拖影。预览与实际合并复用同一容量校验。指针取消、窗口失焦或按 Esc 清掉拖影，拖出行囊松手保留原位置。短点击仍用于选择或查看报价，拖拽不触发点击出售。

## 实机验证

- [浏览器回归](../../v2/tests/bag-drag-check.mjs)实测缩放后的行囊、狐市和战利品页，三个场景的拖影偏差都小于 1 CSS 像素，落格一致。另验证拖动多格、右键旋转指向的物品、移动前旋转、可合并与已满、移出边界、Esc、从侧袋和货堆拖入、狐市两次点击出售，以及 390 宽 Chrome 触屏拖放与触控取消。测试用固定路签及货物布局复现。
- 单测 116 通过、2 跳过。普通与离线构建通过。触屏为浏览器模拟。
