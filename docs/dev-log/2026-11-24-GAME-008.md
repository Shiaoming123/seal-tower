## 为什么

用户：灯灰这类希望能堆叠；希望能主动丢东西；实际玩时第一层背包就满了。后来补充：丢货本身没关系，难的是资源取舍不好判断，建议「每层可以无限拿，离开或去下一层时选择性抛弃」，由我决定。

模拟先量了现状：机器人每到狐市都卖货，离开每层时行囊仍有八成满，第一、二、三层因为装不下被迫丢掉的货平均 1.5、5.2、5.7 件。

## 做了什么

### 堆叠

- 一格大小的货可以叠：灯灰一格 5 个，其他一格货 3 个（`stackMax`）。拿到同样的货先叠上去，叠满再另占一格。
- 叠着的货按件数算：套装、卖价、库银价、委托、灯灰加成都按件数。卖货、被偷、烧掉、放进侧袋都只拿走一个。易碎货磕坏时只坏一个，坏的那个另放。
- 拖一叠货到另一叠同样的货上，放得下就合并；货堆或侧袋里的货拖到同类的叠上也会叠进去。
- 行囊里显示「×N」，详情写「×N · 一格叠 M 个」。旧存档没有件数字段，按 1 件读。

### 丢掉

物品详情新增「丢掉」，点两下确认；一叠货每次丢一个。原来的「拿出来」改名为「放回货堆」。

### 每层货堆（选择性抛弃）

- 装不下的货不再在关掉奖励或事件时消失，而是进本层的「货堆」，在这一层一直跟着你：不生效，不会被偷，在狐市可以直接卖（点两下），委托也能直接用货堆里的货交。
- 离开楼层（上楼、回镇结算）时，货堆里没装进行囊的会留下。楼梯口会提示「货堆里还有 N 件没装进行囊，离开这一层就会留下」，有「整理行囊」按钮；「上楼」「回镇结算」变成两步：第一下显示「留下 N 件，上楼」。[楼梯口](assets/GAME-008-stairs.jpg)
- 取舍从每打完一场都要纠结一次，集中到离开楼层这一刻：那时已经知道这一层拿到了什么、狐市收价、委托还缺什么。
- 试玩记录多一行「上楼或回镇时留下 N 件货」。

### 数值

机器人以前常因为行囊满了丢掉精英给的装备和委托给的药；有了货堆后它在上楼前把东西装好，胜率从 44–46% 升到 52–63%。真人本来就会腾地方装装备，所以这更多是机器人变得像真人了。调整：

| 改动 | 原因 |
| --- | --- |
| 狐市收货价 75% → 60% | 货不再丢，卖货收入回到改之前的水平（每层约 18 / 60 / 60 石） |
| 第二、三层普通妖伤害各 +1 | 胜率拉回 |
| 各层精英伤害 +1 | 同上 |

调整后（200 局 × 4 把兵器，会卖货）：照影剑 39%、木挡板 38%、引灯盘 47%、算盘 43%；装不下留下的货每层 0.2 / 1.2 / 0 件，离开时行囊占用 71% / 82% / 83%。不卖货的机器人 29–46%。

机器人统计新增「装不下丢掉的货」和「离开时行囊占用」两列（`docs/sim/report.md` 每层收支表）。

## 限制

- 套装表 `docs/sim/sets.md` 没有重跑，是 GAME-006 时的数字；堆叠后凑妖材套装更容易了。
- 机器人只在上楼前自动装货，不会挑哪件留下，所以「留下的货」接近 0 不代表真人不用做取舍。
