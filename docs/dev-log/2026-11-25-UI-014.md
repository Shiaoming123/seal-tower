## 为什么

参赛会话跑创空间检查时发现：桌面 1280×720 下，最后一层守关奖励的说明一长（没取到的材料、货堆提醒），离开按钮就被挤到画面下方，整页又不能滚，几乎点不到。打不过这一步就没法回镇结算。

复现：三层守关打赢，掉落 7 种货、两行说明、货堆 9 件，再加上法宝三选一和选牌，桌面上按钮落在 y=938，画面只有 720 高。

## 改了什么

- 右栏（法宝、选牌）照旧可以滚动，但离开按钮固定在右栏底部，内容滚到它下面去。竖屏本来就整页滚动，按钮不固定。
- 奖励页第二行至少留 260 像素；如果标题区本身就超出画面，整页可以滚动，作为兜底。
- 新增 `v2/tests/reward-fit-check.mjs`：用上面的最坏情况检查桌面不滚动就能点到按钮，竖屏和手机矮屏滚到后能点到。

## 验证

| 检查 | 结果 |
| --- | --- |
| 奖励页按钮 | 桌面按钮从 y=938 回到 652–702，可点；竖屏、手机矮屏可点 |
| 类型检查、单测 | 113 项通过 |
| 死按钮、概念提示可点 | 0 个、全部可点 |
| 全界面 | 桌面、竖屏、手机矮屏都是 0 处 |
| e2e | 桌面、竖屏都通过，无页面报错 |

## 限制

- 右栏内容很多时，选牌区要往下滚才看得全；按钮固定在底部会盖住最下面一小段，滚到底就露出来。
