## 为什么

评审 12-02 开始，评委多半用手机打开、只玩一局。用魔搭手机页面的可视区域（390×664，触屏）像第一次玩的人一样走了一遍：标题、镇灯铺接单、进塔、事件、第一场战斗、奖励、狐市。

## 走查发现和处理

| 画面 | 发现 | 处理 |
| --- | --- | --- |
| 进塔提示 | 写的是「W 前进、A/D 转身、S 后退」，还说「点右边小地图」，竖屏的小地图在下面 | 触屏设备改为「点前进、左转、右转按钮走路，也可以直接点小地图上的格子」；鼠标键盘设备保留按键说明。两套都不再说小地图在哪一边 |
| 探索 | 3D 画面固定 330 高，小地图下面空着一截 | 竖屏网格改为：3D 画面占剩下的高度（至少 330），小地图那栏按内容高度。[改前](assets/UI-007-explore-before.jpg) · [改后](assets/UI-007-explore-after.jpg) |
| 各处按钮 | 「知道了 Enter」「行囊 B」「牌组 C」、卡牌角上的出牌编号，都是键盘快捷键 | 触屏设备上隐藏 `kbd`、卡牌编号和新的 `.keys-only` 文字 |
| 战斗提示 | 「点牌就能打出……按 E 结束回合」，手机上其实是先点放大、再点打出（UI-005） | 用和两步出牌相同的判断（竖屏或无悬停），改说「点一张牌会放大，再点一次才打出……最后点『结束回合』」。[两步出牌](assets/UI-007-picked-card.jpg) |
| 行囊 | 「右键或 R 旋转」、拖动时的「R 旋转」 | 触屏上隐藏（手机用详情里的「旋转」按钮） |
| 狐市 | 卖货面板只有 380 高，「离开狐市」按钮贴底固定，压在行囊格子上，委托只露半截 | 竖屏上半块改为占 52%（最少 380、最多 560），卖货面板放得下格子、委托和按钮。[改前](assets/UI-007-shop-before.jpg) · [改后](assets/UI-007-shop-after.jpg) |
| 标题 | 「声望 0 · 进塔 0 次」压在人物的红头巾上，看不清 | 加深色描边阴影 |

看过、没改的：

- **字偏小。** 竖版舞台 600 宽，在 390 宽的手机上缩到 0.65 倍，委托卡的小字实际只有 9–10 像素。整体放大要改所有竖屏布局，离提交只剩几天，风险大，先不动。
- **奖励页左上那块能滚动**，套装栏在框底被裁住，玩家不一定知道能滚。属于正常的滚动，暂不改。
- 镇灯铺、事件、战斗、奖励的布局在手机上都正常（镇灯铺 UI-006 刚修过）。

所有改动都只作用于竖屏或触屏，桌面版不受影响。
