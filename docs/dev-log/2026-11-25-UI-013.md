## 为什么

参赛会话在跑创空间检查时发现：战斗里点掉第一条「知道了」提示之后，REVIEW-001 新加的「新概念」提示（意图、格挡等）排在 3D 画面后面，桌面 1280×720 下它的按钮点下去落在画面上，玩家看不到也点不到。

原因：概念提示是普通文档流里的块，而战斗和探索的 3D 画面是绝对定位铺满的，后者盖在前者上面。探索画面里的「灯油、签、委托」提示也有同样的问题（被挤到画面下方）。狐市、行囊里的提示在普通版面里，没有问题。

## 改了什么

- `ConceptTip` 加 `float` 参数，探索和战斗里传入，提示改为绝对定位，和「知道了」提示同一层（z-index 6）、同一位置：探索在左上，战斗在手牌上方，竖屏战斗再往上挪。
- 新增 `v2/tests/tip-reach-check.mjs`：桌面和竖屏下，探索、战斗、点掉一条后的下一条，都检查按钮中心点到的就是按钮本身。

## 验证

| 检查 | 结果 |
| --- | --- |
| 类型检查 | 通过 |
| 概念提示可点 | 桌面、竖屏的探索、战斗、战斗第二条都能点到 |
| 全界面 | 桌面、竖屏、手机矮屏都是 0 处 |
| 死按钮 | 0 个 |

## 限制

- 竖屏战斗里提示会盖住妖的半身，点「知道了」后就收起。
- 同一时间 AI 首玩试玩（REVIEW-002）也报了这两处：探索里提示被裁、战斗里「意图」提示挡住意图本身。新位置在手牌上方，不再挡意图。
