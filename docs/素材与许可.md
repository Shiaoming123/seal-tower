# 素材与许可

- 仓库 [MIT](../LICENSE) 适用于项目供开源的代码及随附软件文档。素材文件保留各自的许可、来源记录和适用权利范围。
- Ma Shan Zheng、霞鹜文楷、Noto Sans SC 三套游戏子集依原 SIL Open Font License 1.1 分发。版权、条款及固定输入版本随包。[字体来源与三份许可](../first-cut/type/README.md)
- `assets/` 和 `first-cut/sprites/` 保存项目使用的图像。项目文档区分程序绘制、项目生成的原图与派生图。原图资料包只汇入项目记录所指向且能找到的生成图，另附 SHA-256 清单。[生成与素材记录](../evidence/桥驿画面改版/素材记录.md) · [历史货图记录](../evidence/参赛短局/素材与参考.md)
- 音效主要由项目的 Web Audio 代码生成。导出录屏是对应试玩版本的证据。
- 用户分享的商业游戏对照截图、别的项目、私人资源索引和浏览器工作目录不随包分发。PixelFX、GDQuest 等从项目记录所链接的上游核对。历史资料中的提及只是研究线索。[像素特效研究](../evidence/狐市异货/像素特效研究.md)
