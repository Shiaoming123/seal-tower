# 报名发帖步骤（小红书）

用户本人操作。帖子正文见 [报名构想帖-v2.md](报名构想帖-v2.md)，配图在 [media/post/](media/post/)。

## 1. 把图传到手机

在 Mac 访达里打开 `seal-tower/docs/contest/media/post/`，全选 7 张图，右键「共享 → 隔空投送」发到手机，存进相册。按文件名顺序选图：

1. `01-封面-绯绡.jpg`（封面，必须第一张）
2. `02-白狐反转.jpg`
3. `03-第一人称迷宫.jpg`
4. `04-卡牌战斗.jpg`
5. `05-行囊构筑.jpg`
6. `06-可疑的白狐摊.jpg`
7. `07-回镇营建.jpg`

## 2. 在小红书发笔记

1. 打开小红书 App，点底部中间的「+」，选「从相册选择」，按上面的顺序勾 7 张图，点「下一步」。
2. 第一张就是封面。小红书默认按 3:4 裁切，封面本来就是 3:4，不用裁；实机截图是 16:9，可以选「原比例」或在编辑页逐张调成不裁切。
3. **标题**（最多 20 字）：`塔里两位狐老板娘，有一位是假的`
4. **正文**：从 [报名构想帖-v2.md](报名构想帖-v2.md) 的「正文」一节复制，粘贴到正文框。最后两行是话题和 @，粘贴进来是纯文字，要按下一步重新选一遍。
5. **话题**：把正文末尾那行话题删掉，在正文最后输入 `#`，依次搜索并**点选**下面 5 个话题（点选后会变成蓝色可点的话题，纯文字不算）：
   - `AI无限开发者创作大赛`
   - `AI造游戏`
   - `赞奇科技XSUPERZONE`
   - `华硕AI智能体电脑`
   - `盛趣游戏`
6. **@ 官方账号**：把正文末尾那行 @ 删掉，输入 `@`，搜索并点选 `Qoder CN` 和 `魔搭ModelScope社区`。认准官方账号（一般带认证标）。官网写的是「@Qoder CN」；如果搜不到，选搜索结果里 Qoder 的官方账号。
7. **发布设置**：
   - 可见范围选「公开」，不要选「仅自己可见」或「仅互关好友」。
   - 如果有「内容声明」或「添加声明」，选「内容包含 AI 生成」或类似选项（图里的角色是 AI 生成的，比赛也要求如实说明）。
   - 不要加地点、商品链接之类无关的东西。
8. 点「发布」。

## 3. 拿到帖子链接

发布后打开这篇笔记，点右上角「分享」（或「…」），选「复制链接」。在电脑浏览器（未登录小红书）里打开这个链接，确认别人能看到。

## 4. 在官网报名

1. 电脑打开赛事官网 https://mseo-ai-inf.ms.show/ ，点「报名参赛」。
2. 按页面提示登录（应该是魔搭账号）。
3. 把帖子链接粘贴进去，按页面要求填其他信息，提交。
4. 截图保存「提交成功」或审核状态页面，发给 Claude 归档到 `docs/contest/media/`。

## 5. 之后

- 帖子一直保持公开，评审结束（12-07）前别删、别改成私密。
- 审核要时间。如果被退回，按退回理由改帖子再交，12-01 12:00 前都能补。
- 新的宣传主视觉（ART-008）画好后，可以用在手记、创空间和视频上；帖子换不换封面再说。
