## 检查结果（Claude，2026-11-24）

按原尺寸逐张看缩略图：

- **绯绡（300×400）：** 「斩妖塔」和「富婆狐商救救我！」都读得清；标题在帷幔暗区，没压耳朵和发簪。眨眼、贴脸的铜钱、按在狐扣上的手都看得见。柜台上的秤、铜钱、狐扣、账本、灯灰包露在暗角之上，台词落在柜台正面。台词两行读得清，署名和底部标签偏小但能认。
- **白狐（300×400）：** 标题同上。冰蓝眼、捏钱的手看得清；摊布下的尾尖和发光眼睛在缩略图里只剩一点亮蓝，要点开大图才明显，靠台词「那这位白尾巴的，又是谁？」引人点开。
- **横版（640×360）：** 左上标题和两行标签在暗墙上读得清，不压灯笼。手牌、带狐扣的行囊、远处的纸灯蛾和意图标记、绯绡都能认出。
- **已知小瑕疵：** 横版里拿牌的手涂了红指甲，主角是男剑客。缩略图里看不出，不影响使用，下次重画时修。

第一版暗角太高，把绯绡柜台上的狐扣、账本和按着狐扣的手压暗了，台词也压在道具上。已把暗角改成只盖住柜台正面，台词下移、字号从 56 px 降到 48 px。
