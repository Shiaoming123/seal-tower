# 宣传美术需求（ART-008，交 Codex 生成，Claude 审）

参赛宣传用的三张主视觉。**不进游戏**，不走 `npm run assets`，不改 `v2/art/`、`exports.json`、美术清单。任务登记见 [协作任务](../协作任务.md) 的 ART-008。

## 为什么要画（按「美术需求要有根据」）

现在的两张封面（[绯绡](media/cover-1080x1440.jpg)、[假狐商](media/cover-fakefox.jpg)）是用游戏内立绘拼的，凑合能用，但差点意思：

- **发虚。** 绯绡的源图只有 1200×900，封面上放大到约 1500 px 宽，发丝、金饰、尾巴的毛边都糊了。
- **不像一张画。** 角色是抠图贴在糊化的场景上，没有光影交互，没有前景，看得出是拼的。
- **构图不是为封面设计的。** 立绘本来给游戏界面用，人物偏左、手被裁掉，顶部和底部也没给标题、钩子台词留干净的位置，只能靠压暗渐变硬塞文字。

这三张图是**每个看到帖子、手记、创空间的人第一眼看到的东西**。报名帖的封面决定有没有人点进来，人气奖又按创空间点赞数算，所以值得为它专门画。用户的要求是：以妩媚的狐商当看板娘，先把人勾进来。

每张都交**无字版**。标题和台词由我们用游戏字体（马善政楷书、霞鹜文楷）在代码里加，保证字体可商用、改字不用重画。下面写的「留白区」就是给文字留的位置：那里画面要暗、要简单，不放脸和手。

### 统一要求

- **画风：** 和游戏现有立绘一致，高细节像素风插画（硬边、有限色板、可以有抖动），国风志怪、修仙市井。参考 `first-cut/sprites/fox-settle-hands.webp`（绯绡眨眼拈钱）、`first-cut/sprites/fox-offer-hands.webp`、`v2/art/event-fake-fox.png`（白狐）、`assets/market.webp`（狐市灯笼场景）。
- **角色一致：** 绯绡和白狐的脸型、发型、发饰、服装、配色要和游戏里一致，玩家进游戏能认出是同一个人。
  - **绯绡：** 深棕长卷发，黑色狐耳（耳内红），绿眼，左眼下泪痣，额前金链红宝石，金色花簪和流苏，酒红底金纹的宽袖袍，红指甲，**三条**红白狐尾。
  - **白狐（假狐商）：** 深紫黑长发盘髻，白色狐耳，冰蓝色竖瞳，玉簪，蓝白青花纹的露肩长裙，**九条**蓬松白尾。笑容太标准，有点假。
- **完整场景，不透明背景。** 要有前景、中景、背景和统一的光源，不是抠图贴背景。
- **尺度：** 妩媚、有魅力，但适合小红书和魔搭公开展示：服装不比游戏里现有立绘更暴露，不要性暗示的姿势和镜头。
- **手：** 五根手指，拈铜钱的手指要真的捏住钱（游戏里白狐的手返工过一次）。
- **不要：** 文字、水印、签名、Logo、UI 元素、真实品牌。

### `promo-feixiao` · 绯绡看板娘（P0）

**想要的感觉：** 你刚从塔里爬出来，满身是灰，掀开狐市的门帘。灯笼底下，柜台后面的老板娘抬眼冲你一笑，眨了一下眼，把一枚铜钱贴在脸边：「这枚狐扣，卖不卖？」又好看，又精明，又有点危险。

**画面：**

- 绯绡从腰部以上入画，身体微侧，脸朝镜头，**眨右眼**，嘴角带笑。一只手把方孔铜钱贴在脸颊边；另一只手搭在柜台上，指尖按着一枚完整的铜狐扣（游戏里的「完整狐扣」，`v2/src/assets/clasp.webp`）。
- 前景是她的柜台：深色木纹，台面上摆一杆小铜秤、一小摞铜钱、一本红封皮账本、几件妖货（一小包灰色灯灰、一枚狐扣），被灯笼照得发亮。
- 背景是狐市内部：挂满暖橙色灯笼和红色帷幔，远处虚化（用像素画的方式虚化，不要照片景深）。左侧或背后可以隐约看到一座多层古塔的剪影，透过门洞或窗。
- 三条红白狐尾在她身后展开，至少一条尾巴伸进画面前景，压在柜台边缘，把人物和前景连起来。
- **光：** 主光是左上方的暖色灯笼光，打亮脸、铜钱和金饰；右侧一点冷青色的补光，勾出头发和尾巴的轮廓。

**构图：**

- 人物占画面中部偏下，脸大约在高度 35%–45% 的位置。
- **顶部约 22% 是留白区**（给「斩妖塔」和「富婆狐商救救我！」两行标题）：灯笼和帷幔变暗、变简单，不放耳朵尖以外的重要内容。
- **底部约 20% 是留白区**（给一句台词和一行标签）：柜台正面，深色、纹理简单。
- 小红书信息流里封面会缩到很小：缩成 300 px 宽时，脸、眨眼和那枚铜钱仍要一眼看清。

### `promo-fakefox` · 白狐摊的反转（P1）

**想要的感觉：** 「绯绡说过，塔里只有她一家狐市。」那这位是谁？乍一看和绯绡一样美、一样在笑，再看就发毛。

**画面：**

- 同样是一个狐市摊位，但换成冷色：月光、蓝灰色、灯笼是白纸灯，火光发青。
- 白狐站在摊后，腰部以上，正面略侧，笑容标准，冰蓝竖瞳直视镜头。一只手拈铜钱递向镜头；另一只手藏在宽袖里，袖口露出一截又长又尖的指甲。
- 摊上的货便宜得可疑：价签写着很低的数字也行，但**不要真的写字**，用空白的小木牌表示。
- **反转的钩子：** 摊布一角被掀起（像刚被刀挑开），底下露出层层叠叠的九条白尾巴，比她身后可见的部分多得多。摊布下面的阴影里隐约有一双发光的眼睛，或者一截爪子。
- 背景右侧可以远远看到一点暖橙色：绯绡那家真狐市的灯，和这里的冷色形成对比。
- **构图：** 和 `promo-feixiao` 一样，顶部 22% 和底部 20% 留白。两张并排时要像一组：同样的机位高度、同样的柜台高度，一暖一冷。

### `promo-banner` · 横版主视觉（P1）

**想要的感觉：** 一眼说清这是什么游戏：第一人称爬塔、卡牌战斗、跑商，看板娘是狐老板娘。

**画面：**

- 第一人称视角，站在照影廊的长廊里（红柱、木格窗、青石砖墙，暖色纸灯笼，参考游戏内迷宫的样子，见 `docs/contest/media/studio-check/desktop-02-explore.jpg`）。
- 画面左下角是玩家的手：一只手攥着三四张卡牌（牌面画成游戏卡的样子：米色纸、红框、圆形费用角标，**牌面不写字**），另一只手提着鼓鼓的布行囊，露出狐扣和灯灰。
- 长廊深处站着一只妖（纸灯蛾或灯鼠，参考 `v2/src/assets/moth.webp`、`rat.webp`），头顶飘着一个小小的意图标记（一把剑的图标加红色光晕，不写数字）。
- 画面右侧三分之一是绯绡的半身，从长廊旁的摊位窗口探出身来，手里拈着铜钱，冲镜头眨眼，像在说「打完了来我这儿卖」。
- **留白区：** 左上约 40%×35% 的区域给标题，墙面和天花板变暗、变简单。
- 缩到 640×360（视频封面缩略图）时，绯绡的脸、卡牌和远处的妖都要能认出来。

## 验收（Claude 审）

逐张检查，任一条不过就退回：

1. **角色一致：** 和游戏立绘对照，脸、发型、发饰、服装、配色、尾巴数（绯绡三条、白狐九条）都对得上。
2. **手和身体：** 手指数、捏钱的接触点、手臂和肩膀的连接、尾巴从身后长出来的位置都合理。
3. **留白区：** 加上标题和台词后，字不压脸、手、铜钱。
4. **缩略图测试：** `promo-feixiao` 缩到 300 px 宽、`promo-banner` 缩到 640×360，主体仍然清楚。
5. **画风：** 和游戏内像素风一致，不是写实照片风，也没有明显的 AI 糊边、多余的手指或乱码纹样。
6. **尺度：** 适合公开平台，不比游戏现有立绘更暴露。
7. **文件：** 尺寸达标、无文字水印，提示词和参考图有记录。
