## 演示视频

`media/demo.mp4`：**82.6 秒，1920×1080，H.264 + AAC 立体声，约 33 MB**，带游戏原声和中文字幕。因为太大，**不进 Git**，只在这台电脑的仓库目录里；换电脑用 `node v2/tests/record-demo.mjs` 重录（约 2 分钟，需要 macOS 和系统 Chrome）。

内容顺序：绯绡封面 → 绯绡的狐市（卖货）→ 第一人称迷宫 → 灯鼠战斗（读招、护货）→ 行囊 → 可疑的白狐摊，揭穿假狐商 → 活着回镇折库银、营建铺子 → 片尾。

录法：画面录标签页，声音直接从游戏的 Web Audio 输出取，再无损合成一个 MP4。开发入口按顺序打开狐市、灯鼠战斗和白狐摊，所以是**按脚本走一遍真实界面**，不是随机一局的录像。细节见开发日志。
