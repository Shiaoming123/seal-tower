# CONTEST-002 报名帖与双封面预审

本轮交付两张加字封面和一份可复制的报名帖草稿，供用户一起确认。远程 Claude 从 [协作任务表](../协作任务.md) 认领后在自己的工作树推进。正式发帖等用户确认。

## 输入

- [绯绡无字母图](media/promo/promo-feixiao.png)与[白狐反转无字母图](media/promo/promo-fakefox.png)，已通过 ART-011 独立画审。[交付日志](../dev-log/2026-11-24-ART-011.md)
- [报名帖原稿](报名构想帖-v2.md)用于对照标题、正文、话题和账号。配图顺序为绯绡、白狐反转，用本轮加字稿更新预审副本中的链接。
- [宣传美术需求](宣传美术需求.md)给出标题和台词留白。[绯绡排版试样](../dev-log/media/ART-011/绯绡门审/300×400文字试排.png)与[白狐排版试样](../dev-log/media/ART-011/终审/白狐-300×400试排.png)可作为字号、间距和位置参考。

## 交付与验收

1. 两张封面沿用 3:4。顶部排游戏名「斩妖塔 · 富婆狐商救救我！」，底部排各自台词。绯绡的台词围绕现在卖狐扣还是背上楼。白狐的台词用「绯绡说过，塔里只有她一家狐市」引出反转。
2. 从**最终加字封面**各缩出一张 300×400 的预览。按原尺寸看标题和台词是否读得清，并检查绯绡的眨眼、捏钱手、柜台手与狐扣，以及白狐的脸、捏钱手和摊布下的反转线索。记录检查结果。
3. 把两张加字封面、两张 300 像素宽预览和报名帖草稿放在 [参赛资料](README.md) 下的独立预审目录 `docs/contest/media/cover-review/`，在任务表链接本次结果。保留已交付的无字母图和既有封面，等用户确认后再推进正式发布。
