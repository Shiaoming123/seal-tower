# 魔搭创空间上传步骤（Static）

创建空间、上传文件、设为公开都要用你自己的魔搭账号，需要你本人来操作。如果想让 Claude 代你做，要在对话里明确同意，并自己在本机配好魔搭访问令牌（`MODELSCOPE_API_TOKEN`）。令牌不要贴进对话。

依据：[官方部署教程 · Static 一节](https://modelscope.cn/posts/434564)，2026-11-24 核对。

## 1. 生成上传包

```bash
cd v2
npm run pack:studio
```

产物：

- `v2/dist-studio-flat/`：**网页上传用这个**。201 个文件全部在同一层（资源和许可文件从子文件夹挪到根目录，`index.html` 的引用已改好）。魔搭网页上传只收文件，不保留文件夹结构，所以不能用带 `assets/` 子文件夹的版本。
- `v2/dist-studio/`：保留 `assets/`、`licenses/` 子文件夹的版本，用 Git 推送时可以用它（Git 会保留文件夹）。
- `v2/dist-studio.zip`：`dist-studio/` 的压缩包，约 5.4 MB，方便传到别的电脑

`README.md` 是创空间的说明卡片，内容来自 [studio-README.md](studio-README.md)。要改卡片文字就改这个文件，再重新打包。

## 2. 上传前自检（可选，约 5 分钟）

```bash
cd v2
node tests/studio-check.mjs
```

脚本模拟魔搭的嵌入方式：游戏放在另一个域名的 iframe 里，用全新浏览器配置，桌面和 390×844 手机触屏各打一整局。另有一遍「爬塔」：补满气血和灯油、揭开地图、进战斗把妖血压到 1，让机器人走完三层，确认每层的图和音乐都能从包里加载（不代表难度）。结果写进 `v2/.cache/studio-check/report.json`，全部通过时退出码为 0。

## 3. 在魔搭上创建 Static 创空间（你来操作）

1. 登录 https://modelscope.cn ，进入 [创空间](https://modelscope.cn/studios)，点右上角「我要创建」。
2. 填写：
   - **名称**：英文和数字，会出现在网址里，建议 `zhanyaota` 或 `seal-tower`
   - **中文名／简介**：`斩妖塔 · 富婆狐商救救我！`，简介可以用「第一人称爬塔 + 卡牌战斗 + 背包构筑 + 跑商经营，网页即玩」
   - **可见性**：先选**私有**，确认能玩再改公开（教程也这样建议）
   - **SDK／部署框架**：**Static**
   - **云资源**：免费 CPU
3. 进入「空间文件」，把 `v2/dist-studio-flat/` **里面的 201 个文件全选**拖进上传区（或点上传区选文件）。不要把文件夹本身拖进去。
   - 上传完会显示「正在提交文件至 Git 仓库中」，十几秒后列出文件和一条 `Update files from uploading` 提交。
   - 页面会多出 `.gitattributes`、`.gitignore`，这是平台自动生成的，正常。
4. 「下一步：部署设置」：部署框架选 **Static**（上传 `index.html` 后通常已自动选好），免费 CPU，推荐镜像，不用加变量，点「确认并部署」。确认页会先检测部署入口文件，检测完按钮才能点，再点一次「确认并部署」。
5. 页面显示「空间正在发布中，预计约 10 分钟」。状态变成「运行中」后打开空间页面，按第 4 步检查。

### 备选：用 Git 上传

在创空间管理页点「通过 Git 上传」，平台会给出仓库地址：

```bash
git clone https://www.modelscope.cn/studios/<你的用户名>/<空间名>.git studio-repo
cp -R v2/dist-studio/. studio-repo/
cd studio-repo
git add -A
git commit -m "斩妖塔 · 富婆狐商救救我！ 参赛版"
git push
```

默认分支一般是 `master`。不要强制推送。推送时按提示用魔搭账号或访问令牌登录。

## 4. 上线后检查（你来做，或同意后由 Claude 用浏览器检查公开页面）

- [ ] 退出登录（或开无痕窗口）打开空间网址，能看到标题页「斩妖塔 · 富婆狐商救救我！」
- [ ] 点「去镇灯铺接单」→「进塔」，能走路、能打一场
- [ ] 右上角「声音」能开关，有配乐和音效
- [ ] 手机打开：竖屏能玩，「前进 / 左转 / 右转」按钮能点
- [ ] 打完一局点「再进一趟」能重开；刷新页面后标题页有「继续上一趟」
- [ ] 一切正常后把可见性改成**公开**，再用无痕窗口确认一次
- [ ] 把公开网址发给 Claude，填进手记稿和清单

免费资源一段时间没人访问会休眠，再访问会自动启动，首屏可能要等十几秒。评审期 12-02 到 12-06，期间别删空间、别改成私有。

## 5. 更新版本

改了游戏以后：`npm run pack:studio` → 重新上传（或在 `studio-repo` 里复制、提交、推送）。`SHA256SUMS.txt` 记录了每个文件的哈希，可以用来核对线上是不是最新版。
