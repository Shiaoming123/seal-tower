# 斩妖塔 · 富婆狐商救救我！

第一人称走迷宫、卡牌战斗、背包构筑和跑货经营的网页 Roguelike。AI+∞ 开发者创作大赛第三期「AI 造游戏」参赛作品。

打开页面就能玩，电脑和手机都行，不用登录，不用安装。

## 怎么玩

1. **接单。** 在镇灯铺选一张委托（灯匠要灯灰、绯绡要完整狐扣、药铺要鼠牙和蛾丝、镇长要负钟君的钟铜），再挑一件兵器。
2. **进塔。** 三层随机迷宫：照影廊、桥驿、钟楼。W／S 或上下键前进后退，A／D 或左右键转身；手机上点屏幕按钮，或点小地图自动走过去。每层开局抽一支签（雨夜、集市日、妖潮……），改变这一层的规则。
3. **打牌。** 妖头上写着它下一手要做什么：抢货、蓄力、缩壳。读招出牌，用对的方式打死它才能取到完整的材料。
4. **整理行囊。** 兵器和工具都是有形状的物件，放进行囊它们的牌才进牌组。货物也占格子。按 B 打开行囊，拖动、旋转、拼格子。
5. **卖还是带回家。** 绯绡的狐市每层收价不同。现在卖，背上楼卖，还是活着带回镇上折成库银营建铺子，由你算。倒在塔里就全丢。

声音按钮在右上角，可以分别调配乐和音效。网址后加 `?seed=任意文字` 可以复现同一座塔。

## 制作

- 玩法、数值、工程、音频：Claude（Anthropic）协助完成，参赛者确定方向并试玩反馈。
