# 真人试玩计划（GAME-001）

2026-11-24 · Claude（玩法）。到目前为止，所有数值和交互都只有自动化测试和模拟机器人验证过，没有真人玩过。这份计划要用 3–5 位第一次玩的人，回答开发日志里攒下来的问题。

- 观察时用：[观察表](观察表.md)
- 玩完后问：[访谈问题](访谈问题.md)
- 结果填到：[结果汇总](结果汇总.md)

## 什么时候做

赛事 12-01 18:00 截止提交，评审 12-02 到 12-06。评委大多也是第一次玩、只玩一局，所以这次试玩基本就是一次预演。

| 时间 | 做什么 |
| --- | --- |
| 11-25 到 11-28 | 找人试玩，每人约 25 分钟 |
| 11-28 到 11-29 | 汇总，按下面的「判定」决定改什么 |
| 11-29 到 11-30 | 修改，重新打包部署 |
| 12-01 上午 | 最后检查后提交 |

## 找谁

- 3–5 位**没玩过本作**的人。最好有 1–2 位玩过《杀戮尖塔》或《背包英雄》这类游戏，另外 1–2 位没玩过。
- 至少 1 位用**手机**玩。手机真机到现在一次都没测过。
- 不找参与开发的人。看过开发过程的人也不算第一次玩。

| # | 问题 | 来源 | 怎么看 | 判定：出现这种情况就改 |
| --- | --- | --- | --- | --- |
| 1 | 能不能说清「现在卖，还是背上楼、带回镇上」 | 台账验收；GAME-004B 把收货价改成镇上的 75% | 访谈第 3 题；记录里卖出和带回的石数 | 3 人里有 2 人说不清 → 狐市卖货时在售价旁边显示「带回镇上值 N 石」 |

## 试玩记录

打开游戏时网址加 `?playtest=1`，之后这台设备上每局结算页都会多一个「复制本局试玩记录」按钮。复制出来是一段纯文字，包括结局、用时、每层离开时的气血、精英打了几只、绕开几只、卖了多少、带回多少、淬炼、磕坏、侧袋、缝衬布和委托。剪贴板不能用时会显示一个文本框，长按全选复制即可。

- 本地：`cd v2 && npm run dev`，打开 `http://localhost:5173/?playtest=1`。
- 线上：用 `https://shiaoming-zhanyaota.ms.show/?playtest=1`。它会跳到魔搭页面，参数会传进游戏（参赛会话 11-24 在桌面和 iPhone 上实测过，见[参赛清单](../contest/README.md)「游戏直链与网址参数」）。直接在 `modelscope.cn/studios/Shiaoming/zhanyaota` 后面加参数传不进去。创空间 11-24 已公开，但线上还是试玩模式加入之前的版本，要等重新打包上传后，结算页才有复制按钮；上传前会先问你。
- 记录不含任何个人信息。

## 现场怎么做（约 25 分钟）

1. **准备（开始前）**：用无痕窗口或新设备，保证是第一次玩的存档。打开带 `?playtest=1` 的网址，声音打开。记下版本（提交号）和设备。
2. **开场只说这一段**，不讲规则：
   > 这是一个还在做的小游戏，我想看看第一次玩的人会怎么玩。没有对错，卡住了也正常，那是游戏的问题。玩的时候想到什么可以说出来，不说也行。我不会教你，除非你卡住太久。
3. **第一局**：让他自己玩到结束。观察者只记，不回答玩法问题。卡住超过 2 分钟才提示一次，并在观察表里记成「干预」。
4. **局后**：结算页先复制试玩记录。然后**等 1 分钟，不提醒**，看他会不会自己点「再进一趟」。会就继续第二局（最多 10 分钟），也复制记录。
5. **访谈**：5 分钟，按[访谈问题](访谈问题.md)的顺序问，不要提示答案。
6. **收尾**：把观察表、两份记录、访谈答案放进 `docs/playtest/记录/P1.md`（用 P1–P5 编号，不写名字）。

远程试玩（只发链接）时：把开场那段话和网址发过去，请对方玩完后发回试玩记录和访谈问题的回答；愿意的话再录个屏。远程拿不到观察表，问题 8、9 只能靠访谈。

## 不在这次范围

- 不测平衡的细节：3–5 个人的胜负说明不了胜率，只用来发现「明显太难或太简单」。
- 不问「你喜不喜欢这个游戏」这类泛泛的问题，只问具体的时刻。
- 不改游戏：试玩期间版本固定，问题都等汇总后统一改。
